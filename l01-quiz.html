#Mock Quiz 1A

Question 1 (3 marks)

For each statement, decide whether it is true or false and give a one-line justification (half a mark for the verdict and half for the reason).

  1. If u⊤v<0u^\top v<0u⊤v<0, then the angle between uuu and vvv is obtuse.
  2. Every orthogonal set of vectors is linearly independent.
  3. ∥x∥∞≤∥x∥2\|x\|_\infty\le\|x\|_2∥x∥∞​≤∥x∥2​ for every x∈Rnx\in\mathbb{R}^nx∈Rn.
Solution & marking
  1. True. Since u⊤v=∥u∥ ∥v∥cos⁡θu^\top v=\|u\|\,\|v\|\cos\thetau⊤v=∥u∥∥v∥cosθ, a negative inner product means cos⁡θ<0\cos\theta<0cosθ<0, so θ∈(90∘,180∘]\theta\in(90^\circ,180^\circ]θ∈(90∘,180∘].
  2. False. An orthogonal set may contain 0\mathbf 00, which is orthogonal to every vector, and any set containing 0\mathbf 00 is dependent. The statement holds for orthogonal non-zero vectors.
  3. True. The largest squared entry cannot exceed the sum of all squared entries:
    ∥x∥∞2=max⁡ixi2≤∑ixi2=∥x∥22.\|x\|_\infty^2=\max_i x_i^2\le\sum_i x_i^2=\|x\|_2^2 .∥x∥∞2​=imax​xi2​≤i∑​xi2​=∥x∥22​.

Question 1 (2 marks)

Solution & marking
  1. Yes. It is the null space of the row (1,−2,1)(1,-2,1)(1,−2,1): it contains 0\mathbf 00, and if two vectors satisfy the equation, so do their sums and scalar multiples. Geometrically it is a plane through the origin.
  2. No. The vector (1,0,0)(1,0,0)(1,0,0) belongs to the set, but (−1)⋅(1,0,0)=(−1,0,0)(-1)\cdot(1,0,0)=(-1,0,0)(−1)⋅(1,0,0)=(−1,0,0) does not, so the set is not closed under scalar multiplication.
