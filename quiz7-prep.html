#Affine functions and convex sets

Definition: Affine function

f(x)=a⊤x+bf(x)=a^\top x+bf(x)=a⊤x+b
a flat function: a line, plane or hyperplane, shifted by bbb. It keeps affine combinations exactly:
f(θx+(1−θ)y)=θf(x)+(1−θ)f(y)f\big(\theta x+(1-\theta)y\big)=\theta f(x)+(1-\theta)f(y)f(θx+(1−θ)y)=θf(x)+(1−θ)f(y)
— with equality, so an affine function is both convex and concave.

Definition: Convex set

A set SSS is convex if the segment between any two of its points stays inside it: x,y∈Sx,y\in Sx,y∈S and 0≤θ≤10\le\theta\le10≤θ≤1 ⇒ θx+(1−θ)y∈S\theta x+(1-\theta)y\in Sθx+(1−θ)y∈S. A disc, a line, a half-plane and all of Rn\mathbb{R}^nRn are convex; a ring (annulus) or two separate blobs are not. The domain of a convex function must be a convex set.

#Convex functions (slides 28–29)

Definition: Convex function

fff is convex if for all x,yx,yx,y in its domain and all θ∈[0,1]\theta\in[0,1]θ∈[0,1]
f(θx+(1−θ)y) ≤ θf(x)+(1−θ)f(y)f\big(\theta x+(1-\theta)y\big)\ \le\ \theta f(x)+(1-\theta)f(y)f(θx+(1−θ)y) ≤ θf(x)+(1−θ)f(y)
Left side: fff at the mixed point (a point on the curve). Right side: the same mix of the two heights (a point on the chord). The chord lies on or above the curve.

#Part 2 — gradient descent (slides 36–50)

#The rule

Optimisation problem (slide 36); in this course, no constraints
min⁡θ L(θ)\min_{\theta}\ \mathcal L(\theta)θmin​ L(θ)
Update every parameter against the sign of its derivative — all at the same time
θ ← θ−α ∇L(θ),α>0\theta\ \leftarrow\ \theta-\alpha\,\nabla\mathcal L(\theta),\qquad \alpha>0θ ← θ−α∇L(θ),α>0
Stop when the gradient is (almost) zero, or the loss barely changes
∥∇L(θ)∥<ε\|\nabla\mathcal L(\theta)\|<\varepsilon∥∇L(θ)∥<ε

Why the minus sign: if ∂L/∂θi>0\partial\mathcal L/\partial\theta_i>0∂L/∂θi​>0, increasing θi\theta_iθi​ increases the loss, so we decrease it; if it is <0<0<0 we increase it. Simultaneous update: compute the whole gradient at the current θ\thetaθ first, then change every parameter.

Too small α\alphaα: slow. Too large: overshoots and may diverge. A small λmin⁡\lambda_{\min}λmin​ (a long narrow valley) makes the last part slow and zig-zaggy.

📄 Original questionPSet 8 · Problem 8 ↗
