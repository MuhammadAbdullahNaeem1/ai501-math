#3. AI overview

  • Intelligence: "the ability to learn, understand, and apply knowledge to adapt to new situations, reason, and solve problems." Human intelligence: problem-solving and reasoning, learning from experience, adaptability, emotional intelligence.
  • Artificial intelligence: "the simulation of human intelligence in machines that are programmed to think and learn like humans." Narrow AI vs general AI; superintelligence. The term AI was coined in 1956 by John McCarthy at a conference.
  • Turing (1950), "Computing machinery and intelligence": can machines think? The Turing test (imitation game): an interrogator C questions a computer A and a human B; Turing predicted that by 2000 a machine would have a 30% chance of fooling a person for 5 minutes.
  • 1960s–1990s: initial optimism gave way to a more realistic perspective; focus areas: machine learning, multi-agent systems, computer vision, planning, game theory, optimisation. Milestones: 1997 IBM Deep Blue, 2012 deep-learning breakthrough.

#CITY at LUMS (Centre for Urban Informatics, Technology and Policy)

The grand challenge: rapid urbanisation, resource scarcity and climate change test city resilience (Lahore's built-up area grew 4.5× 1998–2022; motorcycles 4×, cars 3× 2010–2024; smog). CITY works on research, solutions, outreach and academy, via AI/optimisation/modelling/policy → data generation and analysis → evidence-based decisions → sustainable, inclusive, equitable communities. Case studies: road-network extraction for Lahore (Google Earth/Maps, OSM, manual labelling + ML/image processing; QGIS, Python, OpenCV, SciPy); real-time traffic-flow density from intersection cameras (counts of cars, motorcycles, rickshaws, buses, trucks); land-surface temperature (Landsat 1998/2010/2021: vegetation and water declined, built-up grew, +0.47 °C per year); urban tree-cover estimation with Sentinel-2 feature selection (proposed method 99% pixel accuracy, kappa 0.92 vs ESA WorldCover 0.74); emergency response and PM2.5 air-quality forecasting.
Lesson: real signals are complex, non-stationary, spectrally entangled spatio-temporal data; deep learning used as a black box ignores the frequency structure, mixes components and is hard to interpret — "math-informed AI: decompose first, then learn on the pieces."

#4. Machine learning

What is ML? Automating the process of automation; getting computers to program themselves.

Data+Program→Computer→Output⏟traditional programmingvsData+Output→Computer→Program⏟machine learning\underbrace{\text{Data}+\text{Program}\to\text{Computer}\to\text{Output}}_{\text{traditional programming}}\qquad\text{vs}\qquad\underbrace{\text{Data}+\text{Output}\to\text{Computer}\to\text{Program}}_{\text{machine learning}}traditional programmingData+Program→Computer→Output​​vsmachine learningData+Output→Computer→Program​​

Given examples (training data), make a machine learn system behaviour or discover patterns. Classic example: recognising a hand-written "2" — many styles, some look like 3s or 7s; impossible to hand-code, learnable from examples.

Data → Algorithm → Model. The data are given to us; the algorithm we design; the model f(x)f(x)f(x) is the final output that makes predictions.

  • Linear regression algorithm produces a model = a vector of coefficient values.
  • Decision tree algorithm produces a model = a tree of if-then statements with specific values.
  • Neural network + backpropagation + gradient descent produce a model = a trained (weights assigned) network.

#Nature of ML problems

  1. Supervised learning — the algorithm receives inputs with the correct outputs (all labelled data) → model → prediction.
    • Regression: quantitative prediction on a continuous scale (age from a photo; price of a 10-marla 5-bedroom house in 2050; USD/PKR rate in a year; vaccine efficacy; average monsoon rainfall; cumulative AI501 score; probability of an electricity price decrease; steps per day). Common thread: continuous outputs.
    • Classification: predict a discrete class (gender from photo/handwriting; spam filtering; object/face detection; monsoon temperature normal or abnormal; letter grade in AI501; whether electricity prices will decrease; more than 10 000 steps today?). Categorical outputs: yes/no (binary) or multiple classes (multi-class).
  2. Unsupervised learning — all unlabelled data; the model finds patterns, e.g. clustering.
  3. Semi-supervised learning — labelled + unlabelled data; efficiently accommodate the unlabelled data: build a model from labelled data → place unlabelled data with it → label them (ignore anomalies) → refit on the combined data (data modelling and augmentation).

Training-data collection: x→x\tox→ [model / process or system] →y\to y→y — the process/system is the underlying physical or logical phenomenon mapping inputs to observed outputs; we collect training data by observing it.

Example systems: previous sales, prices, inflation, pandemic → future sales; image → object detection/recognition; consumer transactions → market segmentation (unsupervised); income, credit history, employment, marital status → loan approval.

Typical flow: problem-nature identification → training-data collection → model training → model validation → model deployment.

Remember

ML learns the program from data + outputs; supervised = labelled (regression if continuous, classification if categorical), unsupervised = unlabelled (clustering), semi-supervised = both.

#5. Supervised-learning nomenclature

  • Inputs → features; output → label.
  • Training data: (input, output) pairs with known output, used to train the model.
  • Loss / objective / cost function: how well a trained model approximates the training data.
  • Test data: (input, output) pairs with known output used to evaluate the trained model.

Examples: predicting a stock index price from interest rate and unemployment rate (features = the two rates, label = price, rows = training data, "?" rows = predictions); MNIST — 28×28-pixel digit images, 60 000 training and 10 000 test samples → model hhh → predicted digit.

Exam pattern: How this lecture has been examined

2026 Quiz 1 Q1 (3 marks): tick regression / classification / neither for six tasks — including the trap pairs "probability prices decrease" (regression) vs "whether prices decrease" (classification), and grouping students with no labels (neither — unsupervised). 2025 Mid MCQ 17: essential components of supervised learning.

Remember: The one line for this lecture

AI rests on four pillars of mathematics — linear algebra, geometry, calculus, probability — and machine learning is learning a model hhh from (feature, label) data: regression for continuous labels, classification for categories, judged by a loss on data it has not seen.
