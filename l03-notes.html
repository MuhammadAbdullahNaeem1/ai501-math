#1. Rank

Definition: Rank (slide definition)

The rank of AAA is the minimum of the number of linearly independent rows and the number of linearly independent columns.

  • Row rank: maximum number of linearly independent rows.
  • Column rank: maximum number of linearly independent columns.
Theorem / Key result: Row rank = column rank

For every matrix the two numbers are equal; their common value is rank⁡(A)\operatorname{rank}(A)rank(A). (So the "minimum" in the slide definition is never a real contest.) Consequently
rank⁡(A)≤min⁡(m,n)(A∈Rm×n).\operatorname{rank}(A)\le\min(m,n)\qquad(A\in\mathbb{R}^{m\times n}).rank(A)≤min(m,n)(A∈Rm×n).

Derivation: Why (pivot argument)

Reduce AAA to echelon form. Each pivot occupies its own row and its own column. The non-zero rows (one per pivot) are independent ⇒ row rank = #pivots. The pivot columns are independent and every non-pivot column is a combination of them ⇒ column rank = #pivots. Row operations do not change which column combinations give zero, so this carries back to AAA. Hence both equal the number of pivots. The bound: you cannot have more independent columns than columns (≤n\le n≤n), nor more independent vectors in Rm\mathbb{R}^mRm than mmm (≤m\le m≤m) — "rank is limited by whichever runs out first, ingredients or room".

#Key properties (slide p3)

  1. rank⁡(A)=rank⁡(A⊤)\operatorname{rank}(A)=\operatorname{rank}(A^\top)rank(A)=rank(A⊤) — rows and columns hold the same amount of independent information.
  2. rank⁡(AB)≤min⁡(rank⁡A,rank⁡B)\operatorname{rank}(AB)\le\min(\operatorname{rank}A,\operatorname{rank}B)rank(AB)≤min(rankA,rankB) — "a pipeline is only as wide as its narrowest pipe".
  3. If A∈Rn×nA\in\mathbb{R}^{n\times n}A∈Rn×n is invertible, rank⁡(A)=n\operatorname{rank}(A)=nrank(A)=n (full rank) — an invertible map flattens no direction.

Column space. Column jjj of ABABAB is Abj=b1ja1+⋯+bnjanAb_j=b_{1j}a_1+\dots+b_{nj}a_nAbj​=b1j​a1​+⋯+bnj​an​ — a combination of the columns of AAA. So C(AB)⊆C(A)\mathcal C(AB)\subseteq\mathcal C(A)C(AB)⊆C(A) and rank⁡(AB)≤rank⁡(A)\operatorname{rank}(AB)\le\operatorname{rank}(A)rank(AB)≤rank(A).
Null space. If Bx=0Bx=0Bx=0 then ABx=0ABx=0ABx=0, so N(B)⊆N(AB)\mathcal N(B)\subseteq\mathcal N(AB)N(B)⊆N(AB), hence nullity⁡(AB)≥nullity⁡(B)\operatorname{nullity}(AB)\ge\operatorname{nullity}(B)nullity(AB)≥nullity(B). Both have ppp columns, so by rank–nullity rank⁡(AB)=p−nullity⁡(AB)≤p−nullity⁡(B)=rank⁡(B)\operatorname{rank}(AB)=p-\operatorname{nullity}(AB)\le p-\operatorname{nullity}(B)=\operatorname{rank}(B)rank(AB)=p−nullity(AB)≤p−nullity(B)=rank(B).

#3. Computing rank by row reduction

The reliable method is Gaussian elimination to Row Echelon Form (REF) or Reduced Row Echelon Form (RREF); the number of non-zero rows in REF (= pivots in RREF) is the rank.

Recipe (slide p6): (1) write the augmented or coefficient matrix; (2) apply Gaussian elimination to reach REF or RREF; (3) count the non-zero rows (pivots) — that number is the rank.

Elementary row operations — they never change rank, row space or null space: swap two rows; multiply a row by a non-zero scalar; add a multiple of one row to another. (They reorganise the evidence; a row that was secretly a combination of others becomes a row of zeros.)

REF: all zero rows at the bottom; each row's first non-zero entry (the pivot) is to the right of the pivot above. RREF: additionally every pivot is 1 and is the only non-zero entry in its column.

#4. Column space

Definition: Column space

For A∈Rm×nA\in\mathbb{R}^{m\times n}A∈Rm×n with columns a1,…,an∈Rma_1,\dots,a_n\in\mathbb{R}^ma1​,…,an​∈Rm:

— all possible linear combinations of the columns = everything the map x↦Axx\mapsto Axx↦Ax can output (also called the range).

  • C(A)\mathcal C(A)C(A) is a subspace of Rm\mathbb{R}^mRm (the output space): Ax+Ay=A(x+y)Ax+Ay=A(x+y)Ax+Ay=A(x+y), cAx=A(cx)cAx=A(cx)cAx=A(cx), and A0=0A0=0A0=0.
  • dim⁡C(A)\dim\mathcal C(A)dimC(A) = number of linearly independent columns = rank⁡(A)\operatorname{rank}(A)rank(A).
  • A basis for C(A)\mathcal C(A)C(A): the pivot columns of the original AAA (not of the echelon form).
  • Paint shop: C(A)=span⁡{(1,0,0),(0,0,1)}={(r,0,b)}\mathcal C(A)=\operatorname{span}\{(1,0,0),(0,0,1)\}=\{(r,0,b)\}C(A)=span{(1,0,0),(0,0,1)}={(r,0,b)} — the red–blue plane; yellow is off the menu.

Ax=b has a solution  ⟺  b∈C(A)  ⟺  rank⁡(A)=rank⁡([A∣b]).Ax=b\text{ has a solution}\iff b\in\mathcal C(A)\iff\operatorname{rank}(A)=\operatorname{rank}\big([A\mid b]\big).Ax=b has a solution⟺b∈C(A)⟺rank(A)=rank([A∣b]).

#5. Null space

Definition: Null space

N(A)={x∈Rn∣Ax=0}\mathcal N(A)=\{x\in\mathbb{R}^n\mid Ax=0\}N(A)={x∈Rn∣Ax=0}
— all points mapped to zero by AAA (the "inverse image" of 0∈Rm0\in\mathbb{R}^m0∈Rm). It is a subspace of Rn\mathbb{R}^nRn (the input space). Its dimension is the nullity of AAA.

#Computing a null space: free variables and special solutions

  1. Reduce AAA to (R)REF.
  2. Pivot variables ↔ pivot columns; free variables ↔ non-pivot columns.
  3. For each free variable, set it to 1 and the other free variables to 0, solve for the pivot variables → one special solution.
  4. The special solutions form a basis of N(A)\mathcal N(A)N(A); their number = number of free variables = n−rn-rn−r.

#6. The rank–nullity theorem

Theorem / Key result: Rank–nullity (rank + nullity) theorem

For A∈Rm×nA\in\mathbb{R}^{m\times n}A∈Rm×n:
rank⁡(A)+nullity⁡(A)=n=number of columns of A,i.e.dim⁡C(A)+dim⁡N(A)=n.\operatorname{rank}(A)+\operatorname{nullity}(A)=n=\text{number of columns of }A, \qquad\text{i.e.}\qquad \dim\mathcal C(A)+\dim\mathcal N(A)=n .rank(A)+nullity(A)=n=number of columns of A,i.e.dimC(A)+dimN(A)=n.

Why ("conservation of dimensions"): you start with nnn input knobs. Each input dimension either survives as a new output direction (counted by the rank = pivot columns) or is crushed to 0 (counted by the nullity = free columns). Pivots + free = nnn.

#7. Rank and linear systems; the complete solution

Existence is a column-space question (b∈C(A)b\in\mathcal C(A)b∈C(A)?). Uniqueness is a null-space question: if xpx_pxp​ solves Ax=bAx=bAx=b then so does xp+zx_p+zxp​+z for every z∈N(A)z\in\mathcal N(A)z∈N(A), since A(xp+z)=b+0=bA(x_p+z)=b+0=bA(xp​+z)=b+0=b.

Where this shows up in AI: Why an ML student should care
  • Regression is a column-space problem. Predictions XθX\thetaXθ always lie in C(X)\mathcal C(X)C(X). With many more samples than features (n≫dn\gg dn≫d), C(X)\mathcal C(X)C(X) is a thin slice of Rn\mathbb{R}^nRn and yyy is almost never on it — we choose the closest reachable point: least squares (L05).
  • Redundant features create a null space. Height in cm and in inches ⇒ dependent columns ⇒ θ\thetaθ and θ+tz\theta+tzθ+tz (z∈N(X)z\in\mathcal N(X)z∈N(X)) give identical predictions; the model cannot split credit. Fix: drop duplicates or regularise (ridge, L05). This is the 2024 Mid multicollinearity problem.
  • Compression uses low rank. A rank-rrr matrix is stored with far fewer numbers (outer products) — returns with SVD, PCA, low-rank fine-tuning.
