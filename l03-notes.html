L03 · Matrix Rank, Column Space and Null Space

Lecture 3 (slides "Matrix Rank and Spaces", 10 pages) · Deisenroth §2.6 · Strang Ch. 3

Lecture 3 slides (PDF) Revision notes 03–04 (Part I: rank & spaces) Problem Set 4 PSet 4 solutions Tutorial Worksheet 2 Read them all on this page ↓

This lecture asks three questions about a matrix AAA: what it can produce, how many genuinely different things it can produce, and which inputs it makes invisible. The answers are the column space, the rank and the null space. In order, the notes cover: the definition and properties of rank; its geometric meaning; computing rank by row reduction; the column space and the solvability of Ax=bAx=bAx=b; the null space and how to compute it; the rank–nullity theorem; the complete solution x=xp+xnx=x_p+x_nx=xp​+xn​; and the slide's example together with the connections to machine learning. All linear-algebra working is written in matrix form.

A machine holds three tubes of paint, each described by its (red, green, blue) content: red a1=(1,0,0)a_1=(1,0,0)a1​=(1,0,0), blue a2=(0,0,1)a_2=(0,0,1)a2​=(0,0,1) and purple a3=(1,0,1)a_3=(1,0,1)a3​=(1,0,1). A recipe xxx produces the colour

Q1. Which colours can it make? This is the column space. Q2. How many genuinely different paints does it hold? Purple is red plus blue, so only two — this is the rank. Q3. #1. Rank

🧩Background you needindependence recap, and what rank is counting

Recap from L01. Vectors are dependent if one of them can be built from the others, and independent if none can.

Rank asks: among the columns of a matrix, how many are genuinely new? Look at
A=[123011].A=\begin{bmatrix}1&2&3\\0&1&1\end{bmatrix}.A=[10​21​31​].
Column 3 is column 1 plus column 2, since (1,0)+(2,1)=(3,1)(1,0)+(2,1)=(3,1)(1,0)+(2,1)=(3,1). It brings nothing new, so only two columns are independent: rank⁡A=2\operatorname{rank}A=2rankA=2.

Why can the rank not exceed the number of rows? Each column of this AAA lives in R2\mathbb{R}^2R2, a flat plane, and a plane has only two independent directions. So even if AAA had a hundred columns, its rank could be at most 222. In general the rank is at most the number of rows and at most the number of columns: rank⁡A≤min⁡(m,n)\operatorname{rank}A\le\min(m,n)rankA≤min(m,n).

Definition: Rank (slide definition)

The rank of AAA is the minimum of the number of linearly independent rows and the number of linearly independent columns of AAA.

  • The row rank is the maximum number of linearly independent rows.
  • The column rank is the maximum number of linearly independent columns.
Theorem / Key result: Row rank equals column rank

For every matrix the row rank and the column rank are equal; their common value is rank⁡(A)\operatorname{rank}(A)rank(A). (So the "minimum" in the slide's definition is never a real contest.) As a consequence,
rank⁡(A)≤min⁡(m,n)for every A∈Rm×n.\operatorname{rank}(A)\le\min(m,n)\qquad\text{for every }A\in\mathbb{R}^{m\times n}.rank(A)≤min(m,n)for every A∈Rm×n.

Derivation: Why the two ranks agree

Reduce AAA to echelon form. Each pivot occupies its own row and its own column. The non-zero rows, one per pivot, are independent, so the row rank equals the number of pivots. The pivot columns are independent and every other column is a combination of them, so the column rank also equals the number of pivots. Row operations do not change which combinations of columns vanish, so the conclusion carries back to AAA itself.

The bound rank⁡(A)≤min⁡(m,n)\operatorname{rank}(A)\le\min(m,n)rank(A)≤min(m,n) holds because there cannot be more independent columns than there are columns (nnn), nor more independent vectors in Rm\mathbb{R}^mRm than mmm. In the revision notes' words, rank is limited by whichever runs out first — ingredients or room.

#Key properties (slide p3)

  1. rank⁡(A)=rank⁡(A⊤)\operatorname{rank}(A)=\operatorname{rank}(A^\top)rank(A)=rank(A⊤): the rows and the columns carry the same amount of independent information.
  2. rank⁡(AB)≤min⁡(rank⁡A, rank⁡B)\operatorname{rank}(AB)\le\min\big(\operatorname{rank}A,\ \operatorname{rank}B\big)rank(AB)≤min(rankA, rankB): a pipeline is only as wide as its narrowest pipe.
  3. If A∈Rn×nA\in\mathbb{R}^{n\times n}A∈Rn×n is invertible, then rank⁡(A)=n\operatorname{rank}(A)=nrank(A)=n: an invertible map flattens no direction.
Derivation: Property 2 (PSet 4, Problem 4)

The column space shrinks. Column jjj of ABABAB is
Abj=b1ja1+b2ja2+⋯+bnjan,Ab_j=b_{1j}a_1+b_{2j}a_2+\cdots+b_{nj}a_n ,Abj​=b1j​a1​+b2j​a2​+⋯+bnj​an​,
a combination of the columns of AAA. Hence C(AB)⊆C(A)\mathcal C(AB)\subseteq\mathcal C(A)C(AB)⊆C(A), and so rank⁡(AB)≤rank⁡(A)\operatorname{rank}(AB)\le\operatorname{rank}(A)rank(AB)≤rank(A).

The null space grows. If Bx=0Bx=\mathbf 0Bx=0 then ABx=0ABx=\mathbf 0ABx=0, so N(B)⊆N(AB)\mathcal N(B)\subseteq\mathcal N(AB)N(B)⊆N(AB) and nullity⁡(AB)≥nullity⁡(B)\operatorname{nullity}(AB)\ge\operatorname{nullity}(B)nullity(AB)≥nullity(B). Both matrices have ppp columns, so by the rank–nullity theorem (§6)
rank⁡(AB)=p−nullity⁡(AB)≤p−nullity⁡(B)=rank⁡(B).\operatorname{rank}(AB)=p-\operatorname{nullity}(AB)\le p-\operatorname{nullity}(B)=\operatorname{rank}(B).rank(AB)=p−nullity(AB)≤p−nullity(B)=rank(B).
The inequality can be strict. For A=B=(0100)A=B=\begin{pmatrix}0&1\\0&0\end{pmatrix}A=B=(00​10​) each matrix has rank 111, but AB=0AB=0AB=0 has rank 000. (In 2026 Quiz 5, the statement "the rank of ABABAB can be strictly greater than the rank of AAA" is therefore false.)

Other facts that appear in exams:

  • A non-zero outer product uv⊤uv^\topuv⊤, with u∈R5u\in\mathbb{R}^5u∈R5 and v∈R4v\in\mathbb{R}^4v∈R4, is a 5×45\times45×4 matrix of rank exactly 111, since it is the product of a 5×15\times15×1 and a 1×41\times41×4 matrix. It holds 202020 numbers but is described by only 5+4=95+4=95+4=9, which is the seed of low-rank compression.
  • Full column rank means rank⁡A=n\operatorname{rank}A=nrankA=n, so that every column is new; full row rank means rank⁡A=m\operatorname{rank}A=mrankA=m; a matrix is rank-deficient if rank⁡A<min⁡(m,n)\operatorname{rank}A<\min(m,n)rankA<min(m,n).
  • Duplicating a feature reduces the rank: if X∈R1000×50X\in\mathbb{R}^{1000\times50}X∈R1000×50 has column 505050 equal to column 111, then rank⁡X≤49\operatorname{rank}X\le49rankX≤49 and X⊤XX^\top XX⊤X is singular.
  • rank⁡(A⊤A)=rank⁡(A)\operatorname{rank}(A^\top A)=\operatorname{rank}(A)rank(A⊤A)=rank(A), because the two matrices have the same null space (by the Gram-matrix argument of L02).
Remember

The rank is the number of genuinely independent columns, which equals the number of independent rows and the number of pivots, and it never exceeds min⁡(m,n)\min(m,n)min(m,n).

#2. Geometric interpretation

🧩Background you needlines, planes and volumes

Combinations of one arrow (all its multiples) fill a line through the origin — dimension 111.

Combinations of two non-parallel arrows fill a plane — dimension 222. Think of a sheet of paper through the origin.

Combinations of three arrows that do not lie in one plane fill all of 3-D space — dimension 333.

So "rank =2=2=2" for a 3×33\times33×3 matrix means: its three column arrows all lie in one flat sheet, and their combinations can reach only the points of that sheet, not the whole room.

The rank is the dimension of the space spanned by the columns of AAA. For a 3×33\times33×3 matrix:

Rank The columns … Picture
333 span all of R3\mathbb{R}^3R3 a solid volume
222 lie in a plane through 0\mathbf 00 a flat sheet
111 lie on a line through 0\mathbf 00 a line
000 are all zero the origin alone

Equivalently (in the language of 3Blue1Brown), the rank is the number of dimensions that remain after the matrix squashes space.

#3. Computing rank by row reduction

🧩Background you needelimination: the legal moves on equations

Row reduction is the method you learned at school for solving simultaneous equations, written in a table.

The three legal moves (none of them changes the solutions of the equations):

  1. Swap two rows — reordering equations changes nothing.
  2. Multiply a row by a non-zero number — "2x+4y=62x+4y=62x+4y=6" says the same as "x+2y=3x+2y=3x+2y=3".
  3. Add a multiple of one row to another — if two equations are true, their sum is true too.

A worked 2×22\times22×2 example.
[1236]→  R2 ← R2−3R1  [1200].\begin{bmatrix}1&2\\3&6\end{bmatrix}\xrightarrow{\;R_2\,\leftarrow\,R_2-3R_1\;}\begin{bmatrix}1&2\\0&0\end{bmatrix}.[13​26​]R2​←R2​−3R1​​[10​20​].
The second row became all zeros: it was just three times the first row, so it carried no new information. One non-zero row remains, so the rank is 111.

A pivot is the first non-zero entry in a row of the reduced matrix. Each pivot marks one genuinely independent row — and one independent column — so rank = number of pivots.

The reliable method is Gaussian elimination to row echelon form (REF) or reduced row echelon form (RREF). The number of non-zero rows of the echelon form — equivalently, the number of pivots — is the rank.

The recipe (slide p6). (1) Write down the coefficient matrix (or the augmented matrix). (2) Apply Gaussian elimination until the matrix is in REF or RREF. (3) Count the non-zero rows; that number is the rank.

Elementary row operations are: exchanging two rows; multiplying a row by a non-zero scalar; and adding a multiple of one row to another. None of them changes the rank, the row space or the null space. They reorganise the evidence without creating or destroying any, so a row that was secretly a combination of the others becomes a row of zeros.

In REF, every zero row is at the bottom and the first non-zero entry of each row (its pivot) lies to the right of the pivot in the row above. In RREF, in addition, every pivot equals 111 and is the only non-zero entry in its column.

which tells us that column 3 is −1-1−1 times column 1 plus 222 times column 2. Checking this against the original matrix,

Remember

Eliminate to echelon form and count the pivots; the RREF also shows exactly how each non-pivot column depends on the pivot columns.

#4. Column space

🧩Background you needthe column view of Ax, recapped

From L02: AxAxAx is a combination of the columns of AAA, with the entries of xxx as the amounts:
[100001][x1x2]=x1[100]+x2[001]=[x10x2].\begin{bmatrix}1&0\\0&0\\0&1\end{bmatrix}\begin{bmatrix}x_1\\x_2\end{bmatrix}=x_1\begin{bmatrix}1\\0\\0\end{bmatrix}+x_2\begin{bmatrix}0\\0\\1\end{bmatrix}=\begin{bmatrix}x_1\\0\\x_2\end{bmatrix}.​100​001​​[x1​x2​​]=x1​​100​​+x2​​001​​=​x1​0x2​​​.
Whatever xxx you choose, the middle entry of AxAxAx is 000. So the set of all possible outputs — the column space — is the set of vectors of the form (anything, 0, anything)(\text{anything},\,0,\,\text{anything})(anything,0,anything).

Consequence. The equation Ax=(5,0,2)Ax=(5,0,2)Ax=(5,0,2) has a solution (x=(5,2)x=(5,2)x=(5,2)), but Ax=(5,1,2)Ax=(5,1,2)Ax=(5,1,2) has none, because no choice of xxx can make the middle entry equal 111. Solving Ax=bAx=bAx=b is the same as asking "is bbb one of the possible outputs?"

Definition: Column space

For A∈Rm×nA\in\mathbb{R}^{m\times n}A∈Rm×n with columns a1,…,an∈Rma_1,\dots,a_n\in\mathbb{R}^ma1​,…,an​∈Rm, the column space (or range) of AAA is
C(A)=span⁡(a1,…,an)={ Ax : x∈Rn }.\mathcal C(A)=\operatorname{span}(a_1,\dots,a_n)=\{\,Ax\ :\ x\in\mathbb{R}^n\,\}.C(A)=span(a1​,…,an​)={Ax : x∈Rn}.
It consists of all possible linear combinations of the columns, which is the same as everything the map x↦Axx\mapsto Axx↦Ax can output.

  • C(A)\mathcal C(A)C(A) is a subspace of Rm\mathbb{R}^mRm, the output space, because Ax+Ay=A(x+y)Ax+Ay=A(x+y)Ax+Ay=A(x+y), c Ax=A(cx)c\,Ax=A(cx)cAx=A(cx) and A0=0A\mathbf 0=\mathbf 0A0=0.
  • Its dimension is the number of independent columns: dim⁡C(A)=rank⁡(A)\dim\mathcal C(A)=\operatorname{rank}(A)dimC(A)=rank(A).
  • A basis of C(A)\mathcal C(A)C(A) is given by the pivot columns of the original matrix AAA — not those of its echelon form.
  • For the paint machine, C(A)=span⁡{(1,0,0),(0,0,1)}={(r,0,b)}\mathcal C(A)=\operatorname{span}\{(1,0,0),(0,0,1)\}=\{(r,0,b)\}C(A)=span{(1,0,0),(0,0,1)}={(r,0,b)}, the red–blue plane; yellow is not on the menu.
Theorem / Key result: When is Ax=bAx=bAx=b solvable?

Ax=b has a solution⟺b∈C(A)⟺rank⁡(A)=rank⁡([ A∣b ]).Ax=b\ \text{has a solution}\quad\Longleftrightarrow\quad b\in\mathcal C(A)\quad\Longleftrightarrow\quad \operatorname{rank}(A)=\operatorname{rank}\big([\,A\mid b\,]\big).Ax=b has a solution⟺b∈C(A)⟺rank(A)=rank([A∣b]).
If appending bbb as an extra column raises the rank, then bbb supplied a new direction, so it was not reachable.

#5. Null space

🧩Background you needhomogeneous systems and free variables

A homogeneous system is one whose right-hand side is zero: Ax=0Ax=\mathbf 0Ax=0. It always has the solution x=0x=\mathbf 0x=0; the question is whether it has others.

Free variables. Consider the single equation x1+2x2=0x_1+2x_2=0x1​+2x2​=0. You may choose x2x_2x2​ to be anything — call it ttt — and then x1=−2tx_1=-2tx1​=−2t is forced. The variable you are allowed to choose freely is a free variable:
[x1x2]=[−2tt]=t[−21],t∈R.\begin{bmatrix}x_1\\x_2\end{bmatrix}=\begin{bmatrix}-2t\\t\end{bmatrix}=t\begin{bmatrix}-2\\1\end{bmatrix},\qquad t\in\mathbb{R}.[x1​x2​​]=[−2tt​]=t[−21​],t∈R.
All the solutions are multiples of one vector, (−2,1)(-2,1)(−2,1): they fill a line. That line is the null space.

How to spot free variables after elimination: pivot columns give pivot variables (they are solved for); every other column gives a free variable (it is chosen). Each free variable contributes one direction to the null space.

Definition: Null space

N(A)={ x∈Rn : Ax=0 }\mathcal N(A)=\{\,x\in\mathbb{R}^n\ :\ Ax=\mathbf 0\,\}N(A)={x∈Rn : Ax=0}
is the set of all inputs that AAA sends to zero (the "inverse image" of 0∈Rm\mathbf 0\in\mathbb{R}^m0∈Rm). It is a subspace of Rn\mathbb{R}^nRn, the input space, and its dimension is the nullity of AAA.

Two pictures from the revision notes. A lamp shining straight down maps R3\mathbb{R}^3R3 to the floor R2\mathbb{R}^2R2 through A=(100010)A=\begin{pmatrix}1&0&0\\0&1&0\end{pmatrix}A=(10​01​00​); moving an object vertically does not move its shadow, so N(A)\mathcal N(A)N(A) is the vertical axis. And M=(1224)M=\begin{pmatrix}1&2\\2&4\end{pmatrix}M=(12​24​) squashes the whole plane onto the line through (1,2)(1,2)(1,2), collapsing the line N(M)=span⁡{(2,−1)}\mathcal N(M)=\operatorname{span}\{(2,-1)\}N(M)=span{(2,−1)} to the origin.

Null-space vectors are recipes for redundancy. Each x∈N(A)x\in\mathcal N(A)x∈N(A) records a way in which the columns cancel, ∑jxjaj=0\sum_j x_ja_j=\mathbf 0∑j​xj​aj​=0. Consequently the columns are independent exactly when N(A)={0}\mathcal N(A)=\{\mathbf 0\}N(A)={0}. (In 2026 Quiz 5, "if Ax=0Ax=\mathbf 0Ax=0 has only the trivial solution then the rank is exactly nnn" is true.) And if Ax=0Ax=\mathbf 0Ax=0 for some non-zero xxx, it is the columns of AAA that are dependent — not necessarily the rows, and certainly AAA need not be zero (2024 Mid, MCQ 18).

#Computing a null space: free variables and special solutions

  1. Reduce AAA to REF or RREF.
  2. Variables that correspond to pivot columns are pivot variables; the others are free variables.
  3. For each free variable in turn, set it equal to 111 and the remaining free variables equal to 000, and solve for the pivot variables. The result is a special solution.
  4. The special solutions form a basis of N(A)\mathcal N(A)N(A). There is one for each free variable, so there are n−rn-rn−r of them.

#6. The rank–nullity theorem

🧩Background you needcounting columns two ways

After elimination, every column of AAA is either a pivot column or a free column — never both, never neither.

  • The number of pivot columns is the rank.
  • The number of free columns is the number of free variables, which is the nullity (each free variable gives one special solution, i.e. one direction in the null space).

Adding them counts every column exactly once.

Theorem / Key result: Rank–nullity theorem

For every A∈Rm×nA\in\mathbb{R}^{m\times n}A∈Rm×n,
rank⁡(A)+nullity⁡(A)=n,that is,dim⁡C(A)+dim⁡N(A)=the number of columns of A.\operatorname{rank}(A)+\operatorname{nullity}(A)=n,\qquad\text{that is,}\qquad \dim\mathcal C(A)+\dim\mathcal N(A)=\text{the number of columns of }A .rank(A)+nullity(A)=n,that is,dimC(A)+dimN(A)=the number of columns of A.

Why it holds: conservation of dimensions. We start with nnn input "knobs". Each input dimension either survives as a new output direction, contributing to the rank (a pivot column), or is crushed to zero, contributing to the nullity (a free column). Since every column is either a pivot column or a free column, the two counts add up to nnn.

Common trap: Count columns, not rows

The theorem counts nnn, the number of columns. For the 4×34\times34×3 slide example the total is 333, not 444. Remember also where each space lives: N(A)⊆Rn\mathcal N(A)\subseteq\mathbb{R}^nN(A)⊆Rn (inputs) and C(A)⊆Rm\mathcal C(A)\subseteq\mathbb{R}^mC(A)⊆Rm (outputs). The two cannot be compared unless m=nm=nm=n.

Where this shows up in AI: Why a machine-learning student should care
  • Regression is a column-space problem. The predictions XθX\thetaXθ always lie in C(X)\mathcal C(X)C(X). With far more samples than features (n≫dn\gg dn≫d), C(X)\mathcal C(X)C(X) is a thin slice of Rn\mathbb{R}^nRn and the target yyy is almost never in it, so we settle for the closest reachable point. That is least squares (L05).
  • Redundant features create a null space. If one column is height in centimetres and another is height in inches, the columns are dependent, and θ\thetaθ and θ+tz\theta+tzθ+tz with z∈N(X)z\in\mathcal N(X)z∈N(X) give identical predictions; the model cannot decide how to split the credit. The remedy is to drop duplicates or to regularise (ridge regression, L05). This is the multicollinearity problem of the 2024 Mid.
  • Compression uses low rank. A matrix of rank rrr can be stored as rrr outer products using far fewer numbers — an idea that returns with the SVD, PCA and low-rank fine-tuning of large models.
