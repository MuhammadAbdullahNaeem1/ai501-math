Question 3 (2 marks)

True or false, with a reason.

  1. The Jacobian of f:R3→R2f:\mathbb R^3\to\mathbb R^2f:R3→R2 is a 3×23\times23×2 matrix.
  2. For a function with continuous second derivatives, the Hessian is symmetric.
Solution & marking
  1. False. It is m×n=2×3m\times n=2\times3m×n=2×3: one row per output, one column per input.
  2. True. The mixed partials are equal, ∂2f/∂xi∂xj=∂2f/∂xj∂xi\partial^2f/\partial x_i\partial x_j=\partial^2f/\partial x_j\partial x_i∂2f/∂xi​∂xj​=∂2f/∂xj​∂xi​ (Schwarz/Clairaut).
Remember

Quiz recipe: partials one variable at a time → gradient as a column → Hessian from the gradient (check symmetry); Jacobian is outputs × inputs; ∇(x⊤Px)=(P+P⊤)x\nabla(x^\top Px)=(P+P^\top)x∇(x⊤Px)=(P+P⊤)x; Taylor = value + gradient term + ½ Hessian term.
