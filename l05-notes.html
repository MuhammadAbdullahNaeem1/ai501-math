#1. The regression set-up

Regression = quantitative prediction on a continuous scale: given a data sample, predict a numerical value.

x (input) ⟶ Process or System f(x) → ⊕ n (noise)  y (observed output),y=f(x)+n.x\ (\text{input})\ \longrightarrow\ \boxed{\text{Process or System } f(x)}\ \xrightarrow{\ \oplus\, n\ (\text{noise})\ }\ y\ (\text{observed output}),\qquad y=f(x)+n .x (input) ⟶ Process or System f(x)​  ⊕n (noise) ​ y (observed output),y=f(x)+n.

The process/system is any underlying physical or logical phenomenon mapping inputs to noisy outputs. True model: we assume an inherent but unknown relationship fff. Goal: given noisy observations, estimate the unknown functional relationship as accurately as possible. (Two 40-year-olds may exercise 3 and 5 hours — age cannot explain everything; nnn is everything we didn't measure.)

Term Meaning
one-variable regression output yyy is a scalar (we cover this)
multi-variable regression output y\mathbf yy is a vector
single-feature regression input xxx is a scalar (covered)
multiple-feature regression input x\mathbf xx is a vector (covered)

Examples — single feature: course score from hours of effort per week; monthly e-commerce sales vs advertising cost. Multiple features: machine efficiency from sensors (temperature, vibration); remaining useful life (RUL) of a battery from charge/discharge data; sales volume from demographics, GDP, climate; crop yield from satellite images and gravity data; surge pricing (Uber); driver fatigue/distraction from video; driving quality from car sensors.

Model formulation. Training data D={(x1,y1),…,(xn,yn)}⊆Xd×YD=\{(x_1,y_1),\dots,(x_n,y_n)\}\subseteq\mathcal X^d\times\mathcal YD={(x1​,y1​),…,(xn​,yn​)}⊆Xd×Y (slide example: true f(x)=4.2+2.4xf(x)=4.2+2.4xf(x)=4.2+2.4x). The model y^=f^(x,θ)\hat y=\hat f(x,\theta)y^​=f^​(x,θ) has (1) a structure chosen in advance (linear, polynomial, inverse, …) and (2) parameters θ=[θ1,…,θM]\theta=[\theta_1,\dots,\theta_M]θ=[θ1​,…,θM​] tuned from data. The model error is e=y−y^e=y-\hat ye=y−y^​.

Definition: The modular recipe (linear regression is the course's second learning algorithm)

Unlike kNN, linear regression is modular — the approach used for most of the course:

  1. Select a model. 2. Define a loss function. 3. Formulate an optimisation problem: find parameters minimising the loss. 4. Solve it — analytically (set the derivative to zero) or numerically (an iterative algorithm).
Remember

y=f(x)+ny=f(x)+ny=f(x)+n: we never see fff, only noisy samples; choose a model structure, a loss, then optimise the parameters.

#3. The loss function

The loss is a function of the model parameters. For input xxx the residual error is e=y−y^=y−θ0−θ⊤xe=y-\hat y=y-\theta_0-\theta^\top xe=y−y^​=y−θ0​−θ⊤x — the vertical gap between the observed value and the line.

Why squares? Signs would cancel in a plain sum; squares punish big errors more (4 costs 16× an error of 1), are smooth (differentiable everywhere, unlike ∣e∣|e|∣e∣), give a clean formula, and are the right loss under Gaussian noise (probability part of the course).

How to solve? Analytically: find the critical point where the derivative (if it exists) is zero. Numerically: an algorithm that iteratively moves closer to the minimiser.

#4c. It is a minimum, and when the inverse exists

The Hessian (matrix of second derivatives) of L\mathcal LL is X⊤XX^\top XX⊤X, and v⊤X⊤Xv=∥Xv∥2≥0v^\top X^\top Xv=\|Xv\|^2\ge0v⊤X⊤Xv=∥Xv∥2≥0 — the loss is a bowl, so the flat spot is the global minimum.

X⊤XX^\top XX⊤X is invertible iff the columns of XXX are linearly independent (L02 Gram-matrix proof). It fails with:

  • too little data: need n≥d+1n\ge d+1n≥d+1;
  • redundant features (one column a combination of others — height in cm and in m; feature 50 = 2 × feature 3).

Then X⊤XX^\top XX⊤X is singular and there is a whole line/plane of equally good www ⇒ remove the redundant feature or regularise (§10).

Definition: Underfitting vs overfitting

Underfitting: model too simple — large error on training and new data (high bias). Overfitting: model fits noise — tiny training error, large error on new data (high variance). Zero training error is guaranteed once M≥n−1M\ge n-1M≥n−1 (distinct xxx): that only proves the model can memorise.
