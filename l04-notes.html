In the first three lectures a matrix was a machine we knew, and we asked what it could produce. Machine learning reverses the situation: we observe examples of inputs and outputs, and we must find the machine. The data are still vectors — every patient is a point in Rd\mathbb{R}^dRd, and a dataset is a matrix with one row per patient — and our first learner, kkk-nearest neighbours, uses nothing more than the distances of L01.

In order, this lecture covers: the supervised-learning set-up; loss functions; learning as optimisation, overfitting, and the train/validation/test split; a map of classification methods; the kkk-nearest-neighbour algorithm, including distance metrics, normalisation, the choice of kkk and its cost; the curse of dimensionality; and the evaluation of classifiers — accuracy and its trap, the confusion matrix and its metrics, trade-offs, ROC curves and AUC, FFF-scores and the Matthews correlation coefficient.

#1. The supervised learning setup

🧩Background you needfunctions, pairs and 'drawn from a distribution'

A function hhh takes an input and returns an output. Writing h:X→Yh:\mathcal X\to\mathcal Yh:X→Y means "hhh takes inputs from the set X\mathcal XX and returns outputs in the set Y\mathcal YY". For example, a function that takes a patient's 8 measurements and returns a predicted oxygen level is h:R8→Rh:\mathbb{R}^8\to\mathbb{R}h:R8→R.

A labelled pair (xi,yi)(x_i,y_i)(xi​,yi​) is one example: the inputs xix_ixi​ (a feature vector) together with the correct answer yiy_iyi​ (the label). The training set DDD is just a list of such examples.

"Drawn from an unknown distribution P(X,Y)P(X,Y)P(X,Y)" means: there is some real-world process that produces patients and their outcomes, with certain combinations being common and others rare. We never see the full process — only the nnn examples we happened to collect. The goal is a rule that works for future examples from the same process, not just the ones we have.

The symbol ×\times× between sets (as in Xd×Y\mathcal X^d\times\mathcal YXd×Y) means "pairs": the first element from Xd\mathcal X^dXd, the second from Y\mathcal YY.

Definition: Hypothesis class

The hypothesis class H\mathcal HH is the set of candidate functions — for example all linear models, all neural networks of a given architecture, or all decision trees — from which we select h∈Hh\in\mathcal Hh∈H. #2. Loss functions

🧩Background you needaverages, absolute values and squares

A loss turns "how wrong" into one number. For each example, compute the error ei=h(xi)−yie_i=h(x_i)-y_iei​=h(xi​)−yi​ (prediction minus truth). Then summarise all the errors.

Why not just add the errors? An error of +5+5+5 and an error of −5-5−5 would cancel to 000, hiding two bad mistakes. So we first make every error non-negative:

  • absolute value ∣ei∣|e_i|∣ei​∣ — the size of the error, ignoring its sign;
  • square ei2e_i^2ei2​ — also non-negative, and it makes large errors count much more (102=10010^2=100102=100, but 12=11^2=112=1).

Why divide by nnn? It turns a total into an average per example, so that a dataset of 200 patients and one of 2 million can be compared on the same scale.

The δ\deltaδ in the 0/1 loss is the Kronecker delta from L01: δ0=1\delta_0=1δ0​=1 and δk=0\delta_k=0δk​=0 for k≠0k\neq0k=0. So 1−δh(xi)−yi1-\delta_{h(x_i)-y_i}1−δh(xi​)−yi​​ is 000 when the prediction is exactly right and 111 when it is wrong — it simply counts mistakes.

A loss function L\mathcal LL measures how badly hhh predicts yyy from xxx. Each loss below is normalised by nnn, so it is a loss per sample and datasets of different sizes can be compared. All of them are non-negative.

#3. Learning, overfitting and the train/test split

🧩Background you needwhat 'arg min' means

min versus arg min. For the function f(c)=(c−3)2+1f(c)=(c-3)^2+1f(c)=(c−3)2+1:

  • min⁡cf(c)=1\min_c f(c)=1minc​f(c)=1 is the smallest value of the function;
  • arg⁡min⁡cf(c)=3\arg\min_c f(c)=3argminc​f(c)=3 is the input that achieves it.

In learning we want the arg min — the actual model h∗h^\asth∗ — not just the value of its loss.

Overfitting in one sentence. A model that has memorised the training answers can score perfectly on those answers while having learned nothing that transfers to new questions — exactly like memorising a past paper instead of learning the subject. The only way to detect it is to test on examples the model has not seen.

Learning is an optimisation problem. Once H\mathcal HH and L\mathcal LL are fixed, we look for
h∗=arg⁡min⁡h∈HL(h).h^\ast=\arg\min_{h\in\mathcal H}\mathcal L(h).h∗=argh∈Hmin​L(h).
(The slides write "min", but what we want is the minimiser itself.) This finds an hhh with low loss on our data. The real question, highlighted on the slides, is different: how can we make sure that hhh also has low loss on inputs that are not in DDD?

Definition: The memoriser

How to split. The split must capture the variation in the distribution: use i.i.d. (random) sampling for ordinary data, and for time series split by time, training on the past and testing on the future.

Common trap: The test set is a sealed envelope

You may use the test set only once, after the model has been decided using the training data. Looking at the test error, adjusting the model and looking again turns the test set into training data and makes the reported error optimistic. For the same reason, normalisation statistics must be computed on the training set only.

The validation set. Often DDD is split three ways, for example 80%80\%80% training, 10%10\%10% validation and 10%10\%10% test. The validation data evaluate the loss of an hhh learned from the training data; if the validation loss is high, we change the model and try again.

Worked example: Which set is being used, and is the use legitimate? (revision notes)
  1. Choosing between k=3k=3k=3 and k=7k=7k=7: the validation set or cross-validation — legitimate.
  2. Computing the weights of a neural network by gradient descent: the training set — legitimate.
  3. Reporting "our model is 91%91\%91% accurate": the test set — legitimate, provided it was opened once.

Remember

The training set fits the parameters, the validation set tunes the hyper-parameters, and the test set is opened once; zero training error — the memoriser — proves nothing.

#5. k-Nearest Neighbours (kNN)

🧩Background you needdistances, majority votes and Big-O notation

Distance between two feature vectors is the Euclidean distance from L01: subtract, square, add, square-root. For (1,2)(1,2)(1,2) and (4,6)(4,6)(4,6):
(4−1)2+(6−2)2=9+16=5.\sqrt{(4-1)^2+(6-2)^2}=\sqrt{9+16}=5 .(4−1)2+(6−2)2​=9+16​=5.
Squared distance skips the final square root. It is enough for kNN, because if a<ba<ba<b then a<b\sqrt a<\sqrt ba​<b​ — the order of the neighbours does not change.

Majority vote. Among the kkk neighbours, count how many belong to each class and pick the most common. With labels red, red, blue the vote is red.

Big-O notation describes how the work grows with the data size. "O(dn)O(dn)O(dn)" means "roughly proportional to d×nd\times nd×n": double the number of training points nnn and the work doubles; double the number of features ddd and it doubles too. The exact constant is ignored.

Min–max scaling, step by step. For a feature whose training values range from 202020 to 656565, the value 252525 becomes
25−2065−20=545≈0.11.\frac{25-20}{65-20}=\frac{5}{45}\approx0.11 .65−2025−20​=455​≈0.11.
The smallest value maps to 000 and the largest to 111.

The idea: similar features have similar labels. In the slide's picture with two classes and two features, a query point surrounded by red points should be labelled red. The algorithm is: given a new test point xxx, find the most similar points in the training data, and classify xxx "like" them.

The slides raise three questions: how to measure similarity (the distance metric), how many neighbours to use (the value of kkk), and how to resolve disagreement among the neighbours (majority voting and tie rules).

1-NN, the simplest classifier in machine learning, uses the label of the single closest known point. The generalisation takes the kkk nearest neighbours and assigns their most frequent label. In the slide's picture the same query is labelled red with k=3k=3k=3 but blue with k=7k=7k=7: the answer can change with kkk.

Characteristics of kNN.

  • It is instance-based ("lazy") learning: no model is built during training; the training data are simply stored.
  • It is flexible: it adapts to unseen data by computing distances when a prediction is needed, and it can draw very irregular class boundaries.
  • It makes no assumptions about the distribution of the data.
  • It is non-parametric: no parameters are learned.
  • Its hyper-parameters are kkk and the distance metric.
  • The time and storage needed for prediction grow with the size of the training set.

#Practical issues (slides p25–27)

  • Use an odd kkk for binary classification, so that a two-class vote can never be tied. (With three classes an odd kkk does not prevent ties: k=3k=3k=3 can produce a 111–111–111 vote.)
  • Ties are resolved using prior information (for example, choosing the more common class), or by falling back to the 1-NN or (k−1)(k-1)(k−1)-NN classifier.
  • Missing values are replaced by the average value of that feature, computed on the training data.
  • Categorical features are compared with the Hamming distance, which counts mismatches:

#Choice of kkk

  • With k=1k=1k=1 the classifier is sensitive to noise and has high variance: a single mislabelled point carves out its own island. Increasing kkk makes the algorithm less sensitive to noise.
  • With k=nk=nk=n every query has the same neighbours — all the points — so the classifier always predicts the overall majority class: maximally stable, but blind to the input. Decreasing kkk lets the model capture finer structure in the space.
  • The idea: choose kkk neither too large nor too small; the right value depends on the data. How? Learn it from the data: split into training and validation sets (or use 555- or 101010-fold cross-validation), compute the validation loss for k=1,2,3,…k=1,2,3,\dotsk=1,2,3,… using the training data to find neighbours, and choose the kkk with the smallest validation loss. This is the only learning that kNN requires.
  • In bias–variance terms, a small kkk gives low bias and high variance, and a large kkk gives high bias and low variance (2025 Mid MCQ 19; 2024 MCQ 8). A highly non-linear class boundary favours a small kkk (PSet 4, Problem 6d).
  • At k=1k=1k=1 the training error is 000, since every point is its own nearest neighbour; this tells us nothing. Only the validation error counts.

#7. Evaluating a classifier: accuracy and its trap

The 0/1 loss averaged over the test set is the misclassification rate, an estimate of the probability that a point is classified incorrectly; for each test point the loss is either 000 or 111. Its complement is the accuracy:
accuracy=1−misclassification rate.\text{accuracy}=1-\text{misclassification rate}.accuracy=1−misclassification rate.
The issue: accuracy is not meaningful when the classes are imbalanced or skewed.

Decide which mistake is more expensive, then watch the metric that punishes it (slide p48).

#11. ROC curve and AUC

🧩Background you needthresholds and areas

A threshold. Many classifiers output a score, say a number between 000 and 111 for "how likely is this patient sick". We then choose a cut-off ttt: scores at or above ttt are called positive.

  • A low threshold calls almost everyone positive: few misses, many false alarms.
  • A high threshold calls almost everyone negative: few false alarms, many misses.

The ROC curve shows every choice at once: for each threshold, plot (false-alarm rate, catch rate). Moving the threshold traces a curve from (0,0)(0,0)(0,0) (nobody flagged) to (1,1)(1,1)(1,1) (everybody flagged).

Area under a curve. The AUC is the area of the region beneath that curve inside the unit square. A perfect classifier hugs the top-left corner, giving the whole square, area 111; random guessing follows the diagonal, area 12\tfrac1221​.

Definition: The ROC curve

Move the threshold from strict to lenient and, at each value, plot the point
(FPR, TPR)=(1−Sp, Se).(\text{FPR},\ \text{TPR})=\big(1-S_p,\ S_e\big).(FPR, TPR)=(1−Sp​, Se​).

  • The TPR (sensitivity) is the fraction of positive samples that are correctly identified.
  • The FPR (1−1-1− specificity) is the fraction of negative samples that are incorrectly flagged.
  • The best possible classifier has Se=Sp=1S_e=S_p=1Se​=Sp​=1, the upper-left corner (0,1)(0,1)(0,1).
  • A random guess lies on the diagonal, the line of no discrimination: it has no power.
  • The area under the curve (AUC) quantifies the power of the classifier: 111 is perfect and 0.50.50.5 is random. The "alarmist" who calls everyone sick sits at (1,1)(1,1)(1,1) and the "optimist" who calls everyone healthy at (0,0)(0,0)(0,0).

What AUC really means (beyond the slides). It is the probability that a randomly chosen positive receives a higher score than a randomly chosen negative — a measure of ranking quality that does not depend on any single threshold. A curve lying below the diagonal, with AUC 0.20.20.2, is reliably wrong rather than useless: inverting its predictions gives AUC 0.80.80.8.

🧩Background you needthe harmonic mean

The arithmetic mean of aaa and bbb is a+b2\tfrac{a+b}{2}2a+b​. The harmonic mean is
