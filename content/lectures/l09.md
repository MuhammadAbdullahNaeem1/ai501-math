Training a model means walking downhill on its loss. In order, this lecture covers: **functions** $f:\mathbb{R}^n\to\mathbb{R}^m$ and their types; **differentiation** — the derivative as the limit of secant slopes, the first and second derivatives, the sum, product, quotient and chain rules, the gradient, the Jacobian, the Hessian and the Taylor series; **convex functions**, where every local minimum is global; and the **gradient descent** algorithm with its stochastic and mini-batch versions.

:::intuition The delivery-time problem and the hiker in the fog (revision notes)
A food-delivery app in Lahore has four past orders:

| order $i$ | 1 | 2 | 3 | 4 |
|---|---|---|---|---|
| distance $x_i$ (km) | 1 | 2 | 3 | 4 |
| time $y_i$ (min) | 13 | 17 | 23 | 27 |

The model is a line $\hat y=\theta_0+\theta_1x$ (a fixed cost plus minutes per km), judged by half the mean squared error
$$
\mathcal L(\theta_0,\theta_1)=\frac{1}{2n}\sum_{i=1}^n(\theta_0+\theta_1x_i-y_i)^2,\qquad n=4 .
$$
L05's normal equations give $\theta_0=8$, $\theta_1=4.8$ with $\mathcal L=0.1$. But for a neural network there is no formula: all we can do is start somewhere — e.g. $\theta=(0,0)$, where $\mathcal L=214.5$ — and improve step by step.

Picture the loss as a landscape and yourself as a hiker on the Margalla Hills in thick fog. You cannot see the valley; you can only feel the ground under your boots. **The gradient** is the tilt under your feet, **the Hessian** is how the ground curves, **the Taylor series** is the small map you can sketch from what you feel, **convexity** is the promise that there is only one valley, and **gradient descent** is the walk itself.
:::

## 1. Functions: what we model and optimise

:::figs
l09-p03|A function f: ℝⁿ → ℝᵐ — each input gives exactly one output
l09-p04|Domain, co-domain and image
l09-p06|Types of functions at a glance
:::

:::def Function
A **function** is a relationship between a set of inputs and a set of possible outputs in which **each input is related to exactly one output**. We write
$$
f:\mathbb{R}^n\to\mathbb{R}^m,
$$
where $n$ is the dimension of the input space and $m$ the dimension of the output space. *Example:* $f(x,y)=x^2+y^2$ has $n=2$, $m=1$ ($\mathbb{R}^2\to\mathbb{R}$), and $f(1,2)=1+4=5$.
:::

:::def Domain, co-domain, image
- **Domain:** the set of all possible inputs the function can take; for $f:\mathbb{R}^n\to\mathbb{R}^m$ it is a subset of $\mathbb{R}^n$ (e.g. $x>0$ for $\log x$).
- **Co-domain:** the set in which the outputs are expected to lie — $\mathbb{R}^m$.
- **Image** (sometimes called the **range**): the set of all **actual** values $f$ produces inside the co-domain. It can be smaller than the co-domain: $f(x)=x^2$ has co-domain $\mathbb{R}$ but image $[0,\infty)$ — no input gives $-1$.
:::

**Vocabulary (slide p5).**

- **Scalar-valued** functions: $m=1$, the output is a single number. **Vector-valued** functions: $m>1$, the output is a vector in $\mathbb{R}^m$.
- **Univariate** ($n=1$), **bivariate** ($n=2$, written $f(x,y)$) and **multivariate** ($n>2$, written $f(\mathbf x)$ with $\mathbf x\in\mathbb{R}^n$) functions.

**Types at a glance (slide p6).**

| | $m=1$ (scalar output) | $m>1$ (vector output) |
|---|---|---|
| $n=1$ | **curve**: $f(x)=x^2$, price vs house size | **path in space**: $r(t)=(\cos t,\sin t)$ |
| $n=2$ | **surface**: $x^2+y^2$, a loss $\mathcal L(\theta_0,\theta_1)$ | **vector map**: $f(x,y)=(x^2,xy)$ |
| $n>2$ | **scalar field**: a loss $\mathcal L(\theta)$, $\theta\in\mathbb{R}^d$; $w^\top x+b$ | **map $\mathbb{R}^n\to\mathbb{R}^m$**: a neural-network layer $\sigma(Wx+b)$ |

**Focus of this lecture:** a loss $\mathcal L(\theta)$ of many parameters ($n>2$, $m=1$), which gradient descent minimises.

### Examples (slides p7–8)

:::figs
l09-p07|Linear and quadratic functions
l09-p08|Polynomial functions
:::

| Function | Shape |
|---|---|
| $f(x)=ax$ ($n=1$) | line through the origin |
| $f(x)=ax+b$ | line, shifted up by $b$ |
| $f(x)=a^\top x$ ($n$ inputs) | hyperplane through the origin |
| $f(x)=a^\top x+b$ | hyperplane, shifted by $b$ |
| $f(x)=x^\top x$ | bowl (paraboloid), minimum at $0$ |
| $f(x)=x^\top Ax$ (generalised quadratic) | **bowl or saddle, depending on $A$** |

Linear functions are **flat**, with the same slope everywhere; quadratic functions are **curved** — a bowl when $A$ is positive definite and a saddle when $A$ is indefinite (exactly L07's classification). **Polynomial** functions $f(x)=a_0+a_1x+\cdots+a_px^p$ capture non-linear relationships; a cubic ($p=3$) can follow curvature that a straight line ($p=1$) misses, yet it is still **linear in the coefficients** $a_0,\dots,a_3$, so L05's fitting tools apply.

:::example A neural-network layer (revision notes, Brainteaser 1)
$f(x)=\sigma(Wx+b)$ with $W\in\mathbb{R}^{3\times5}$ and $\sigma(u)=1/(1+e^{-u})$ applied entrywise. $Wx$ needs $x\in\mathbb{R}^5$ and gives a vector in $\mathbb{R}^3$, so $n=5$, $m=3$ and the co-domain is $\mathbb{R}^3$. The sigmoid only produces values strictly between 0 and 1, so the image lies inside the open cube $(0,1)^3$ — **not** the whole co-domain (no input gives $(2,0,0)$).
:::

:::remember
A function $f:\mathbb{R}^n\to\mathbb{R}^m$ gives exactly one output per input; the domain is what it accepts, the co-domain where outputs may land, and the image what it actually produces.
:::

## 2. The derivative

:::figs
l09-p10|Derivative = rate of change; zoom in; local information
l09-p13|The secant line and the average rate of change
l09-p14|The derivative as the limit of secant slopes: the tangent line
l09-p15|Summary: f′ is the slope, f″ the curvature
:::

:::background slope of a line, and what a limit means
- **Slope** = rise over run: through two points $(x_0,y_0)$ and $(x_1,y_1)$ the slope is $\dfrac{y_1-y_0}{x_1-x_0}$.
- **A limit** describes what a quantity approaches as something gets arbitrarily close to a value, **without** plugging the value in. For example $\dfrac{(1+\Delta x)^2-1}{\Delta x}=\dfrac{2\Delta x+\Delta x^2}{\Delta x}=2+\Delta x$ for every $\Delta x\neq0$; as $\Delta x\to0$ it approaches $2$, even though at $\Delta x=0$ the fraction is $0/0$.
:::

**Differentiation** computes derivatives. A derivative means three things (slide p10):

- **Rate of change:** how fast $f$ changes as $x$ moves, $f'(x)=dy/dx$.
- **Zoom in:** near any point, a smooth curve looks like a straight line — the **tangent**.
- **Localised information:** $f'(x_0)$ depends only on how $f$ behaves **close to $x_0$** — exactly the hiker's situation: what you feel under your boots says nothing about the valley three hills away.

**From secant to tangent (slides p11–14).** Take $P=(x_0,f(x_0))$ and $Q=(x_0+\Delta x,\ f(x_0+\Delta x))$.

- **Horizontal change:** $\Delta x$, the distance between $x_0$ and $x_0+\Delta x$.
- **Vertical change:** $\Delta y=f(x_0+\Delta x)-f(x_0)$.
- The line through $P$ and $Q$ is the **secant line**; its slope
$$
\frac{\Delta y}{\Delta x}=\frac{f(x_0+\Delta x)-f(x_0)}{\Delta x}
$$
is the **average rate of change** of $f$ over $[x_0,x_0+\Delta x]$, and approximates the derivative.
- As $\Delta x$ becomes very small, the secant becomes the **tangent line** at $P$, whose slope is the **instantaneous rate of change**.

:::def Derivative
$$
f'(x_0)=\frac{dy}{dx}\bigg|_{x_0}=\lim_{\Delta x\to0}\frac{f(x_0+\Delta x)-f(x_0)}{\Delta x},
$$
the slope of the tangent line to the graph of $f$ at $x_0$. The **second derivative** $f''(x)=\dfrac{d}{dx}\big(f'(x)\big)$ is the rate of change of $f'$; higher-order derivatives (third, fourth, …) give more information about concavity and curvature.
:::

:::example Secants of $f(x)=x^2$ at $x_0=1$ (revision notes, Figure 1)
$$
\frac{(1+\Delta x)^2-1^2}{\Delta x}=\frac{2\Delta x+\Delta x^2}{\Delta x}=2+\Delta x .
$$
For $\Delta x=1.5,\ 0.8,\ 0.3$ the secant slopes are $3.5,\ 2.8,\ 2.3$ — falling towards $2$, the slope of the tangent, as $Q$ slides towards $P$. So $f'(1)=2$.

*Brainteaser 2:* for $f(x)=x^3$ at $x_0=1$ with $\Delta x=0.1$, the secant slope is $(1.1^3-1)/0.1=3.31>f'(1)=3$, because $x^3$ bends upwards there (in general it is $3+3\Delta x+\Delta x^2\to3$).
:::

**What the signs tell you (slide p15).**

| sign | meaning | hiker's reading |
|---|---|---|
| $f'>0$ | rising ↗ | ground goes up ahead |
| $f'<0$ | falling ↘ | ground goes down ahead |
| $f'=0$ | flat: possible minimum or maximum (or neither) | level ground |
| $f''>0$ | slope increasing: bends **up** (convex) | you are in a dip |
| $f''<0$ | slope decreasing: bends **down** (concave) | you are on a crest |

Gradient descent uses the first row; the Hessian (§6) and convexity (§8) are the many-variable versions of the second.

:::remember
The derivative $f'(x_0)=\lim_{\Delta x\to0}\frac{f(x_0+\Delta x)-f(x_0)}{\Delta x}$ is the slope of the tangent — a local rate of change; $f''$ measures curvature ($>0$ bends up, $<0$ bends down).
:::

## 3. Rules of differentiation, and the chain rule along paths

:::figs
l09-p16|Sum, product and quotient rules
l09-p17|Chain rule; the multi-variable chain rule as a sum over paths
:::

:::background derivatives you must know by heart
$$
\frac{d}{dx}x^n=nx^{n-1},\qquad \frac{d}{dx}e^x=e^x,\qquad \frac{d}{dx}\log x=\frac1x,\qquad \frac{d}{dx}\sin x=\cos x,\qquad \frac{d}{dx}\cos x=-\sin x,\qquad \frac{d}{dx}c=0 .
$$
A constant factor stays: $\frac{d}{dx}(5x^3)=15x^2$. For a **partial** derivative (§4) treat every other variable as a constant: $\frac{\partial}{\partial x}(3xy)=3y$.
:::

| Rule | Formula | Slide example |
|---|---|---|
| **Sum** | $\big(f+g\big)'=f'+g'$ | $(x^2+\sin x)'=2x+\cos x$ |
| **Product** | $\big(fg\big)'=f'g+fg'$ | $(x^2\sin x)'=2x\sin x+x^2\cos x$ |
| **Quotient** | $\left(\dfrac fg\right)'=\dfrac{f'g-fg'}{g^2}$ | $\left(\dfrac{\sin x}{x}\right)'=\dfrac{x\cos x-\sin x}{x^2}$ |
| **Chain** | $y=f(g(x))\Rightarrow\dfrac{dy}{dx}=f'(g(x))\,g'(x)$ | $\sin^2x$: $f(u)=u^2$, $g=\sin x$ ⇒ $2\sin x\cos x=\sin 2x$ |

**The chain rule** — the one that matters most for AI — says: **multiply the rates along the chain.**

### Several variables: multiply along each path, add over paths

If $f(x_1,x_2)$ where $x_1(s,t)$ and $x_2(s,t)$ both depend on $s$ and $t$, a change in $s$ reaches $f$ along **two routes** (through $x_1$ and through $x_2$):
$$
\frac{\partial f}{\partial s}=\frac{\partial f}{\partial x_1}\frac{\partial x_1}{\partial s}+\frac{\partial f}{\partial x_2}\frac{\partial x_2}{\partial s},\qquad
\frac{\partial f}{\partial t}=\frac{\partial f}{\partial x_1}\frac{\partial x_1}{\partial t}+\frac{\partial f}{\partial x_2}\frac{\partial x_2}{\partial t}.
$$
$\partial f/\partial s$ is the **sum over every path from $s$ up to $f$** of the products of the derivatives along the path.

:::example The path rule (revision notes, Brainteaser 3)
Let $f=x_1x_2$ with $x_1=s+t$ and $x_2=st$. The pieces: $\frac{\partial f}{\partial x_1}=x_2=st$, $\frac{\partial x_1}{\partial s}=1$, $\frac{\partial f}{\partial x_2}=x_1=s+t$, $\frac{\partial x_2}{\partial s}=t$. So
$$
\frac{\partial f}{\partial s}=st\cdot1+(s+t)\cdot t=2st+t^2 .
$$
Check directly: $f=(s+t)st=s^2t+st^2$, so $\partial f/\partial s=2st+t^2$ ✓.
:::

:::example Problem Set 8, Problem 1 — the derivative of the sigmoid
:::orig [PSet 8 · Problem 1 ↗](pdfs/psets/PSet-08.pdf#page=1)
Let $f(x)=\dfrac{1}{1+e^{-x}}$ be the logistic sigmoid. Show that $f'(x)=f(x)\big(1-f(x)\big)$.
:::
*(Solution written for this site — PSet 8 has no official solutions yet.)* Write $f=(1+e^{-x})^{-1}$ and use the chain rule with outer $u^{-1}$ and inner $u=1+e^{-x}$, whose derivative is $-e^{-x}$:
$$
f'(x)=-(1+e^{-x})^{-2}\cdot(-e^{-x})=\frac{e^{-x}}{(1+e^{-x})^2}=\underbrace{\frac{1}{1+e^{-x}}}_{f(x)}\cdot\underbrace{\frac{e^{-x}}{1+e^{-x}}}_{1-f(x)} ,
$$
since $1-f(x)=\dfrac{1+e^{-x}-1}{1+e^{-x}}=\dfrac{e^{-x}}{1+e^{-x}}$. Hence $f'=f(1-f)$.
:::

:::ml Backpropagation is this picture
A neural network is a long dependency graph from weights to loss. Backpropagation computes $\partial\mathcal L/\partial w$ for every weight by exactly this rule — multiply along each path, add over paths — reusing the shared pieces instead of recomputing them. Every deep-learning library is, at its core, a chain-rule machine.
:::

:::remember
Sum, product and quotient rules, and the chain rule: multiply the rates along a chain, and with several variables add the products over every path.
:::

## 4. The gradient: which way is steepest

:::figs
l09-p18|The gradient, standard examples, and f = x² + y²
:::

A **partial derivative** $\partial f/\partial x_j$ is the ordinary derivative in $x_j$ with every other input held fixed.

:::def Gradient
For $f:\mathbb{R}^d\to\mathbb{R}$, the gradient stacks all the partial derivatives into a column:
$$
\nabla f(x)=\begin{bmatrix}\dfrac{\partial f}{\partial x_1}&\dfrac{\partial f}{\partial x_2}&\cdots&\dfrac{\partial f}{\partial x_d}\end{bmatrix}^\top\in\mathbb{R}^d .
$$
It quantifies the rate of change along different directions.
:::

**Simple example (slide).** $f(x,y)=x^2+y^2$: $\dfrac{\partial f}{\partial x}=2x$, $\dfrac{\partial f}{\partial y}=2y$, so
$$
\nabla f(x,y)=\begin{bmatrix}2x\\2y\end{bmatrix}.
$$

**Standard gradients** (derived in L05 §4):
$$
\nabla(a^\top x)=\nabla(x^\top a)=a,\qquad \nabla(x^\top x)=2x,\qquad \nabla(x^\top Px)=2Px\ \ (P\text{ symmetric}).
$$

:::derive $\nabla(x^\top Px)$ with index sums (1 November lecture)
Write the quadratic form out as a double sum:
$$
f(x)=x^\top Px=\sum_{i=1}^n\sum_{j=1}^nx_i\,P_{ij}\,x_j .
$$
Differentiate with respect to one coordinate $x_k$. A term $x_iP_{ij}x_j$ contains $x_k$ only when $i=k$ or $j=k$; every other term is a constant and differentiates to $0$. By the product rule on $x_i\cdot x_j$ (with $\partial x_i/\partial x_k=1$ if $i=k$, else $0$):
$$
\frac{\partial f}{\partial x_k}=\underbrace{\sum_jP_{kj}x_j}_{\text{terms with }i=k}+\underbrace{\sum_iP_{ik}x_i}_{\text{terms with }j=k}=(Px)_k+(P^\top x)_k .
$$
(The term $i=j=k$, $P_{kk}x_k^2$, appears once in each sum, which correctly gives $2P_{kk}x_k$.) Stacking over $k$,
$$
\nabla(x^\top Px)=(P+P^\top)\,x,\qquad\text{and if }P=P^\top:\quad \nabla(x^\top Px)=2Px .
$$
With $P=I$ this gives back $\nabla(x^\top x)=2x$.

**Check on a non-symmetric $2\times2$.** $P=\begin{bmatrix}1&2\\0&3\end{bmatrix}$: $f=x_1^2+2x_1x_2+3x_2^2$, so directly $\nabla f=(2x_1+2x_2,\ 2x_1+6x_2)$; the formula gives $(P+P^\top)x=\begin{bmatrix}2&2\\2&6\end{bmatrix}x$ ✓. Only the symmetric part of $P$ matters, which is why we usually take $P$ symmetric.
:::

**The delivery gradient.** Differentiating the loss term by term (chain rule on each square),
$$
\frac{\partial\mathcal L}{\partial\theta_0}=\frac1n\sum_{i=1}^nr_i,\qquad \frac{\partial\mathcal L}{\partial\theta_1}=\frac1n\sum_{i=1}^nr_ix_i,\qquad r_i=\theta_0+\theta_1x_i-y_i .
$$
At $\theta=(0,0)$ every residual is $-y_i$, so $\nabla\mathcal L=-(\bar y,\ \overline{xy})=(-20,\ -56)$. Both entries are negative: increasing either parameter lowers the loss, and $\theta_1$ matters almost three times as much.

### Why "steepest", and why perpendicular to the contours

:::thm The directional derivative
The rate of change of $f$ when you step in a **unit** direction $u$ is
$$
D_uf=\nabla f^\top u=\|\nabla f\|\cos\varphi ,
$$
where $\varphi$ is the angle between $u$ and $\nabla f$ (chain rule along the line $x+hu$, and L01's angle formula).
:::

- $\varphi=0$: the largest rate $+\|\nabla f\|$ — so **$\nabla f$ points in the direction of steepest ascent** (uphill).
- $\varphi=180^\circ$: the most negative rate — so **$-\nabla f$ is the direction of steepest descent**.
- $\varphi=90^\circ$: rate zero, $f$ does not change. Moving along a contour (a curve where $f$ is constant) is exactly this, so **$\nabla f$ is perpendicular to the contours.**

Strictly, the directional derivative is the **number** $D_uf$ for one direction; the gradient is the **vector** that produces all of them (its $j$-th entry is the directional derivative along the $j$-th axis). The slide's phrase "gradient (directional derivative)" is shorthand.

:::example Steepest descent on $f(x,y)=x^2+3y^2$ at $(1,1)$ (revision notes, Brainteaser 4)
$\nabla f=(2x,6y)=(2,6)$, with $\|\nabla f\|=\sqrt{40}\approx6.32$. The fastest decrease is along $-\nabla f/\|\nabla f\|=-\tfrac{1}{\sqrt{10}}(1,3)\approx(-0.32,-0.95)$, at rate $\sqrt{40}$ per unit step. Any direction perpendicular to $(2,6)$, e.g. $\tfrac{1}{\sqrt{10}}(3,-1)$, gives rate 0: it is tangent to the contour $x^2+3y^2=4$ through $(1,1)$. Note the gradient does **not** point straight at the minimum: steepest is a local fact.
:::

:::example Problem Set 8, Problems 2–3 — gradients with the chain rule
:::orig [PSet 8 · Problems 2–3 ↗](pdfs/psets/PSet-08.pdf#page=1)
**P2.** Let $f(z)=\log(1+z)$ with $z=x^\top x$ and $x\in\mathbb{R}^D$. Use the chain rule to compute $\nabla f$ (the gradient with respect to $x$), and state the dimension of each quantity you use.
**P3.** Compute $\nabla f$ for $f(x)=\operatorname{tr}(xx^\top+\sigma^2I)$, where $x\in\mathbb{R}^D$ and $I$ is the $D\times D$ identity. *(Hint: write out the outer product $xx^\top$ explicitly.)*
:::
*(Solutions written for this site.)*

**P2.** $\dfrac{df}{dz}=\dfrac{1}{1+z}$ is a scalar ($1\times1$); $\nabla_x z=\nabla(x^\top x)=2x\in\mathbb{R}^D$. By the chain rule,
$$
\nabla f=\frac{df}{dz}\,\nabla_xz=\frac{2x}{1+x^\top x}\in\mathbb{R}^D .
$$
**P3.** The diagonal of $xx^\top$ is $(x_1^2,\dots,x_D^2)$ and the trace is linear, so
$$
f(x)=\operatorname{tr}(xx^\top)+\sigma^2\operatorname{tr}(I)=\sum_{j=1}^Dx_j^2+\sigma^2D=x^\top x+\sigma^2D\qquad\Longrightarrow\qquad \nabla f=2x .
$$
:::

:::remember
$\nabla f$ stacks the partial derivatives; it points in the steepest uphill direction and is perpendicular to the contours, so $-\nabla f$ is the steepest way down. Know $\nabla a^\top x=a$, $\nabla x^\top x=2x$, $\nabla x^\top Px=2Px$.
:::

## 5. The Jacobian: many outputs at once

:::figs
l09-p19|The Jacobian: one row per output, one column per input
:::

When the output is a vector, $f:\mathbb{R}^n\to\mathbb{R}^m$, each of its $m$ components has its own gradient. Lay those gradients down as **rows**:

:::def Jacobian
$$
J_f(x)=\begin{bmatrix}\dfrac{\partial f_1}{\partial x_1}&\cdots&\dfrac{\partial f_1}{\partial x_n}\\\vdots&\ddots&\vdots\\\dfrac{\partial f_m}{\partial x_1}&\cdots&\dfrac{\partial f_m}{\partial x_n}\end{bmatrix}=\begin{bmatrix}\nabla f_1^\top\\\vdots\\\nabla f_m^\top\end{bmatrix}\in\mathbb{R}^{m\times n},\qquad (J_f)_{ij}=\frac{\partial f_i}{\partial x_j}.
$$
**One row per output, one column per input.** Each row is the gradient of one component of $f$.
:::

**Slide example.** $f(x,y)=\begin{bmatrix}x^2\\xy\end{bmatrix}$:
$$
J_f(x,y)=\begin{bmatrix}\dfrac{\partial}{\partial x}(x^2)&\dfrac{\partial}{\partial y}(x^2)\\[4pt]\dfrac{\partial}{\partial x}(xy)&\dfrac{\partial}{\partial y}(xy)\end{bmatrix}=\begin{bmatrix}2x&0\\y&x\end{bmatrix}.
$$

**The slide's question: what is the Jacobian of $f(x)=Ax$?** Row $i$ of $Ax$ is $a_i^\top x$ (with $a_i^\top$ the $i$-th row of $A$), whose gradient is $a_i$. So row $i$ of $J$ is $a_i^\top$, and
$$
\boxed{J_{Ax}=A}.
$$
This is the many-variable version of $(ax)'=a$: a linear map is its own best linear approximation.

:::thm What the Jacobian means
Near $x$, $f(x+\delta)\approx f(x)+J_f(x)\,\delta$: the Jacobian is the matrix that best imitates $f$ locally. For a scalar function ($m=1$) it is the single row $\nabla f^\top$.

**Chain rule as matrix multiplication (beyond the slides):** if $h(x)=f(g(x))$ then $J_h=J_f\,J_g$. The "sum over paths" of §3 is exactly what a row-times-column product computes, and a deep network's derivative is a product of layer Jacobians.
:::

:::example A $3\times2$ Jacobian (revision notes, Brainteaser 5)
$f(x,y)=(x+y,\ xy,\ x^2)$ has three outputs and two inputs, so $J$ is $3\times2$:
$$
J=\begin{bmatrix}1&1\\y&x\\2x&0\end{bmatrix},\qquad J(1,2)=\begin{bmatrix}1&1\\2&1\\2&0\end{bmatrix}.
$$
:::

:::remember
The Jacobian of $f:\mathbb{R}^n\to\mathbb{R}^m$ is the $m\times n$ matrix $J_{ij}=\partial f_i/\partial x_j$ (row $i$ = gradient of output $i$); $J_{Ax}=A$, and the chain rule is $J_{f\circ g}=J_fJ_g$.
:::

## 6. The Hessian: how the ground curves

:::figs
l09-p20|The Hessian matrix of second partial derivatives
l09-p21|f = x² + y², and the eigenvalues of H classify the shape
l09-p22|The Hessian of least squares is XᵀX — constant
:::

:::def Hessian
For a twice-differentiable $f:\mathbb{R}^n\to\mathbb{R}$, the Hessian is the $n\times n$ matrix of second-order partial derivatives:
$$
H_f(x)=\begin{bmatrix}\dfrac{\partial^2f}{\partial x_1^2}&\dfrac{\partial^2f}{\partial x_1\partial x_2}&\cdots&\dfrac{\partial^2f}{\partial x_1\partial x_n}\\[4pt]\dfrac{\partial^2f}{\partial x_2\partial x_1}&\dfrac{\partial^2f}{\partial x_2^2}&\cdots&\dfrac{\partial^2f}{\partial x_2\partial x_n}\\\vdots&\vdots&\ddots&\vdots\\\dfrac{\partial^2f}{\partial x_n\partial x_1}&\dfrac{\partial^2f}{\partial x_n\partial x_2}&\cdots&\dfrac{\partial^2f}{\partial x_n^2}\end{bmatrix}.
$$
- **Diagonal:** the curvature along each axis.
- **Off-diagonal:** how two variables interact (does the slope in $x_1$ change as you move in $x_2$?).
- **Symmetric**, $H=H^\top$, whenever the second partials are continuous.
:::

**Interpretation (slide p20).** The Hessian is the extension of the second derivative; it describes the **local curvature** of $f$, and it is used to assess the **convexity** of a function and in **second-order optimisation** methods (Newton's method).

**The quickest way to compute it:** the Hessian is the **Jacobian of the gradient**, $H_f=J_{\nabla f}$ — differentiate each entry of $\nabla f$ again.

**Slide example.** $f(x,y)=x^2+y^2$: $\dfrac{\partial^2f}{\partial x^2}=2$, $\dfrac{\partial^2f}{\partial y^2}=2$, $\dfrac{\partial^2f}{\partial x\partial y}=0$, so
$$
H_f(x,y)=\begin{bmatrix}2&0\\0&2\end{bmatrix}:
$$
the same curvature in every direction.

### The eigenvalues of $H$ classify a critical point

At a **critical point** (flat spot, $\nabla f=\mathbf 0$), the eigenvalues of $H$ decide what kind it is — L07's definiteness test, applied to curvature. Each eigenvector is a direction, and its eigenvalue is the curvature of $f$ along it.

| eigenvalues of $H$ | $H$ is | shape | slide example |
|---|---|---|---|
| all $>0$ | positive definite | **bowl: local minimum** | $x^2+y^2$: $\lambda=2,2$ |
| all $<0$ | negative definite | **cap: local maximum** | $-x^2-y^2$: $\lambda=-2,-2$ |
| mixed signs | indefinite | **saddle point** | $x^2-y^2$: $\lambda=2,-2$ |

:::derive why a positive definite Hessian means "bowl"
Near a critical point $a$ (where $\nabla f(a)=\mathbf 0$), the second-order Taylor map of §7 is $f(a+\delta)\approx f(a)+\tfrac12\delta^\top H\delta$. If $H\succ0$, then $\delta^\top H\delta>0$ for every small step $\delta\neq\mathbf 0$, so $f$ rises in **every** direction: a minimum. If $H\prec0$ it falls in every direction (maximum); if $H$ is indefinite it rises along some directions and falls along others (saddle).
:::

:::example Tutorial Worksheet 4, Problem 1 — gradient, Jacobian, Hessian, classification
:::orig [Worksheet 4 · Problem 1 ↗](pdfs/psets/Worksheet-04.pdf#page=1)
Let $f(x,y)=x^2+4xy+y^2$. (a) Find $\nabla f(x,y)$ and the critical point of $f$. (b) The gradient is itself a map $g(x,y)=\nabla f(x,y)=(g_1,g_2)$; compute its Jacobian $J_g$. (c) Write down the Hessian of $f$. What do you notice about it compared with $J_g$? (d) Find the eigenvalues of the Hessian and classify the critical point. Confirm by evaluating $f$ at $(1,1)$ and at $(1,-1)$.
:::
**(a)** $\dfrac{\partial f}{\partial x}=2x+4y$ and $\dfrac{\partial f}{\partial y}=4x+2y$, so
$$
\nabla f=\begin{bmatrix}2x+4y\\4x+2y\end{bmatrix}=\begin{bmatrix}2&4\\4&2\end{bmatrix}\begin{bmatrix}x\\y\end{bmatrix}.
$$
Setting it to $\mathbf 0$: the matrix has determinant $4-16=-12\neq0$, so it is invertible and the only solution is the **critical point $(0,0)$**.

**(b)** $g_1=2x+4y$ and $g_2=4x+2y$; one row per output, one column per input:
$$
J_g=\begin{bmatrix}\partial g_1/\partial x&\partial g_1/\partial y\\\partial g_2/\partial x&\partial g_2/\partial y\end{bmatrix}=\begin{bmatrix}2&4\\4&2\end{bmatrix}.
$$
**(c)** $f_{xx}=2$, $f_{yy}=2$, $f_{xy}=f_{yx}=4$, so
$$
H=\begin{bmatrix}2&4\\4&2\end{bmatrix}=J_g .
$$
**The Hessian is the Jacobian of the gradient** — and it is symmetric. (It is constant because $f$ is quadratic: $f=x^\top Px$ with $P=\begin{bmatrix}1&2\\2&1\end{bmatrix}$ and $H=2P$.)

**(d)** $\det(H-\lambda I)=(2-\lambda)^2-16=0\Rightarrow2-\lambda=\pm4\Rightarrow\lambda=6$ or $\lambda=-2$ (check: sum $4=\operatorname{tr}H$, product $-12=\det H$). **Mixed signs: $(0,0)$ is a saddle point.** Confirm: $f(1,1)=1+4+1=6>0$ and $f(1,-1)=1-4+1=-2<0$, while $f(0,0)=0$. So $f$ rises along $(1,1)$ (the eigenvector of $\lambda=6$) and falls along $(1,-1)$ (the eigenvector of $\lambda=-2$). Indeed $f(1,1)=\tfrac12(1,1)H(1,1)^\top=\tfrac12\cdot12=6$.
:::

### The Hessian of least squares (slide p22)

For $f(\theta)=\tfrac12\|X\theta-y\|^2=\tfrac12(X\theta-y)^\top(X\theta-y)=\tfrac12\big(\theta^\top X^\top X\theta-2y^\top X\theta+y^\top y\big)$, with $X\in\mathbb{R}^{n\times d}$, $\theta\in\mathbb{R}^d$, $y\in\mathbb{R}^n$:
$$
\nabla f(\theta)=X^\top(X\theta-y)=X^\top X\theta-X^\top y .
$$
The gradient is **linear** in $\theta$, with the constant matrix $X^\top X$ in front, so differentiating once more,
$$
\boxed{H_f(\theta)=X^\top X}\qquad\text{— constant: the same curvature for every }\theta .
$$
A least-squares loss is a perfect quadratic bowl.

**The payoff: least squares by calculus (outline, Week 8).** Setting this gradient to zero re-derives L05 without any geometry:
$$
\nabla f(\theta)=X^\top X\theta-X^\top y=\mathbf 0\quad\Longrightarrow\quad X^\top X\theta=X^\top y\quad\Longrightarrow\quad \theta^\star=(X^\top X)^{-1}X^\top y
$$
(when the columns of $X$ are independent) — the **normal equations**, the same answer as the projection argument. And since the Hessian $X^\top X$ is a Gram matrix, it is PSD (PD for independent columns, L07): the loss is a bowl and $\theta^\star$ is its bottom.

:::example The delivery valley is a narrow ravine (revision notes)
With the $\tfrac{1}{2n}$ scaling, the delivery loss has
$$
H=\frac1nX^\top X=\begin{bmatrix}1&\bar x\\\bar x&\overline{x^2}\end{bmatrix}=\begin{bmatrix}1&2.5\\2.5&7.5\end{bmatrix},\qquad \lambda_1\approx8.35,\quad \lambda_2\approx0.15
$$
(trace $8.5$, determinant $7.5-6.25=1.25$). Both positive: a bowl. But one is about 56 times the other: a **long, narrow ravine**. The steep direction $(0.32,0.95)$ is mostly $\theta_1$; along the flat direction $(0.95,-0.32)$ raising the fixed cost while lowering the per-km rate nearly cancel on our data. This ravine explains the zig-zag of gradient descent in §9.
:::

:::remember
The Hessian $H_{jk}=\partial^2f/\partial x_j\partial x_k$ is the symmetric matrix of curvatures (the Jacobian of $\nabla f$); at a critical point, all eigenvalues $>0$ is a minimum, all $<0$ a maximum, mixed a saddle. For least squares, $H=X^\top X$.
:::

## 7. The Taylor series: a local map of the ground

:::note Optional for this week's quiz
The quiz notice lists functions and differentiation; Taylor series is on the tutorial worksheet (its Problem 2, worked below) but may not be examined this week. Read it once — it is short and it ties §4–§6 together.
:::

:::figs
l09-p23|The Taylor series: each term matches one more derivative at a
l09-p25|Taylor polynomials of sin x + cos x around 0 (MML book, Fig. 5.4)
l09-p26|Second-order Taylor in many variables: height + tilt + bend
:::

### One variable

The **Taylor series** of $f$ around $x=a$ approximates $f$ by polynomial terms built from its derivatives at $a$:
$$
f(x)=\underbrace{f(a)}_{\text{value}}+\underbrace{f'(a)(x-a)}_{\text{slope (tangent)}}+\underbrace{\frac{f''(a)}{2!}(x-a)^2}_{\text{curvature}}+\frac{f'''(a)}{3!}(x-a)^3+\cdots=\sum_{n=0}^{\infty}\frac{f^{(n)}(a)}{n!}(x-a)^n .
$$
Stopping after the $(x-a)^n$ term gives the **Taylor polynomial** of degree $n$,
$$
T_n(x)=f(a)+f'(a)(x-a)+\frac{f''(a)}{2!}(x-a)^2+\cdots+\frac{f^{(n)}(a)}{n!}(x-a)^n ,
$$
an $n$-term approximation of $f$ near $x=a$. The $k!$ is there so that the $k$-th derivative of the $k$-th term at $a$ comes out exactly $f^{(k)}(a)$.

:::example Problem Set 8, Problem 4 — $f(x)=\sin x+\cos x$ at $x_0=0$ (the slides' Figure 5.4)
:::orig [PSet 8 · Problem 4 ↗](pdfs/psets/PSet-08.pdf#page=1)
Compute the Taylor polynomials $T_n$ for $n=0,1,\dots,5$ of $f(x)=\sin x+\cos x$ at $x_0=0$.
:::
The derivatives cycle: $f=\sin x+\cos x$, $f'=\cos x-\sin x$, $f''=-\sin x-\cos x$, $f'''=-\cos x+\sin x$, $f^{(4)}=f$. At $0$ they are $1,\ 1,\ -1,\ -1,\ 1,\ 1,\dots$ Hence
$$
\begin{aligned}
T_0&=1, & T_1&=1+x, & T_2&=1+x-\tfrac{x^2}{2},\\
T_3&=1+x-\tfrac{x^2}{2}-\tfrac{x^3}{6}, & T_4&=T_3+\tfrac{x^4}{24}, & T_5&=T_4+\tfrac{x^5}{120}.
\end{aligned}
$$
$T_0$ matches only the height, $T_1$ the tilt (it is the tangent line); $T_5$ is already off by $0.4$ at $x=2.5$, while $T_{10}$ stays within $0.07$ of $f$ on $[-4,4]$: **higher-order Taylor polynomials approximate $f$ better and more globally.**
:::

:::warn "More terms" is not "good everywhere"
A Taylor polynomial is built from information at **one point**. Near $a$ it is excellent; far from $a$ even a high-degree $T_n$ can be wildly wrong (look at $T_5$ at $x=4$). The hiker's map is reliable only a few steps from where she stands — the reason gradient descent takes small steps.
:::

:::example $\sqrt{4.1}$ from $T_1$ and $T_2$ (revision notes, Brainteaser 7)
$f(x)=\sqrt x$ at $a=4$: $f(4)=2$, $f'(x)=\tfrac12x^{-1/2}\Rightarrow f'(4)=\tfrac14$, $f''(x)=-\tfrac14x^{-3/2}\Rightarrow f''(4)=-\tfrac1{32}$.
$$
T_1=2+\tfrac14(0.1)=2.025,\qquad T_2=2.025-\tfrac12\cdot\tfrac1{32}(0.01)=2.02484375 .
$$
True value $2.024846\ldots$: $T_1$ is off by about $1.5\times10^{-4}$, $T_2$ by about $2\times10^{-6}$.
:::

### Many variables

For $f:\mathbb{R}^n\to\mathbb{R}$, the gradient takes the place of $f'$ and the Hessian the place of $f''$:
$$
f(x)\approx T_2(x)=\underbrace{f(a)}_{\text{height at }a}+\underbrace{\nabla f(a)^\top(x-a)}_{\text{tilt: the tangent plane}}+\underbrace{\tfrac12(x-a)^\top H_f(a)(x-a)}_{\text{bend: the curvature}} .
$$
**Gradient descent uses the first two terms; Newton's method also uses the curvature term.**

:::example Tutorial Worksheet 4, Problem 2 — a second-order Taylor polynomial
:::orig [Worksheet 4 · Problem 2 ↗](pdfs/psets/Worksheet-04.pdf#page=1)
Let $f(x,y)=x\,e^y$ and $a=(2,0)$. (a) Compute $f(a)$, $\nabla f(a)$ and the Hessian $H(a)$. (b) Write the second-order Taylor polynomial $P_2(x,y)$ of $f$ about $a$. (c) Use $P_2$ to approximate $f(2.1,\,0.1)$ and compare with the exact value $2.1\,e^{0.1}\approx2.32086$. How much of the approximation comes from the first-order terms alone?
:::
**(a)** $f(a)=2e^0=2$. The partials are $f_x=e^y$ and $f_y=xe^y$, so $\nabla f(a)=\begin{bmatrix}1\\2\end{bmatrix}$. The second partials are $f_{xx}=0$, $f_{xy}=f_{yx}=e^y$, $f_{yy}=xe^y$, so
$$
H(a)=\begin{bmatrix}0&1\\1&2\end{bmatrix}.
$$
**(b)** With $\delta=\begin{bmatrix}x-2\\y\end{bmatrix}$,
$$
P_2(x,y)=2+\begin{bmatrix}1&2\end{bmatrix}\delta+\tfrac12\,\delta^\top\begin{bmatrix}0&1\\1&2\end{bmatrix}\delta=2+(x-2)+2y+(x-2)\,y+y^2 ,
$$
since $\tfrac12\big(0\cdot(x-2)^2+2(x-2)y+2y^2\big)=(x-2)y+y^2$.

**(c)** At $(2.1,\,0.1)$, $\delta=(0.1,\,0.1)$:
$$
P_2=2+\underbrace{0.1+0.2}_{\text{first order}=0.3}+\underbrace{0.01+0.01}_{\text{second order}=0.02}=2.32 .
$$
The exact value is $2.32086$, so the error is about $0.00086$ (0.04%). The **first-order terms alone** give $2.3$ (error $0.021$): they supply $0.30$ of the total change $0.32$ — about 94% — and the curvature terms add the remaining $0.02$.
:::

At $a=(0,0)$: $\mathcal L=214.5$, $g=\nabla\mathcal L=(-20,-56)$. Step to $x=a-0.1g=(2,\ 5.6)$, so $x-a=-0.1g$, with $\|g\|^2=3536$ and $g^\top Hg=29520$.

## 8. Convex functions: when there is only one valley

:::note Not in this week's quiz
:::

:::figs
l09-p28|Convex function: the chord lies above the graph
l09-p29|Jensen's inequality f(E[X]) ≤ E[f(X)]
l09-p30|Examples of convex functions
l09-p31|Operations that preserve convexity, and where they show up in ML
l09-p32|First-order condition: the graph lies above every tangent plane
l09-p33|Second-order condition: ∇²f ⪰ 0
l09-p34|The least-squares loss is convex
:::

:::def Convex function
$f:\mathbb{R}^n\to\mathbb{R}$ is **convex** if for all $x,y$ in its (convex) domain and all $\theta\in[0,1]$,
$$
f\big(\theta x+(1-\theta)y\big)\le\theta f(x)+(1-\theta)f(y).
$$
The line segment (chord) between any two points on the graph lies **on or above** the graph. A **concave** function is the opposite: its chords lie below.
:::

The left side is $f$ at a convex combination of $x$ and $y$ (L01); the right side is the same blend of the two heights — the chord.

:::thm Why convexity matters
For a convex function, **every local minimum is a global minimum.** Gradient descent cannot get stuck in a worse valley, because there is no worse valley.
:::

:::derive the short argument
Suppose $x$ were a local minimum but some $y$ were lower, $f(y)<f(x)$. On the chord from $x$ to $y$, convexity gives $f(\theta x+(1-\theta)y)\le\theta f(x)+(1-\theta)f(y)<f(x)$ for every $\theta<1$ — including points as close to $x$ as you like. So $x$ was not a local minimum after all.
:::

**Jensen's inequality (slide p29).** For a convex $f$ and a random variable $X$,
$$
f\big(\mathbb E[X]\big)\le\mathbb E\big[f(X)\big].
$$
With $X$ equal to $x_1$ or $x_2$ with probability $\tfrac12$ each, this is the definition with $\theta=\tfrac12$: the chord lies above the curve, so the **average of $f$** is at least **$f$ of the average**. *Example:* $X\in\{1,3\}$ and $f(x)=x^2$: $f(\mathbb E X)=4$ and $\mathbb E f(X)=5$; the difference $\mathbb E X^2-(\mathbb E X)^2=1$ is the **variance** — Jensen for $x^2$ says a variance is never negative.

**Examples (slide p30)** — each checked by curvature $\ge0$:

| function | why convex | note |
|---|---|---|
| linear $a^\top x+b$ | second derivative 0 | convex **and** concave |
| quadratic $x^\top Qx+b^\top x+c$ | $\nabla^2=2Q\succeq0$ | needs $Q\succeq0$ (PSD) |
| $e^x$ on $\mathbb{R}$ | $(e^x)''=e^x>0$ | |
| $-\log x$, $x>0$ | $(-\log x)''=1/x^2>0$ | so $\log$ is concave |
| norms $\|x\|_p$, $p\ge1$ | triangle inequality | kink at 0, still convex |

($\succeq$ is the generalised inequality "is positive semi-definite".) For a **non-symmetric** $Q$, the Hessian of $x^\top Qx$ is $Q+Q^\top$, so test $\tfrac12(Q+Q^\top)$.

**Operations that preserve convexity (slide p31):**

- **Non-negative weighted sums:** $f_1,\dots,f_k$ convex $\Rightarrow g=\sum_i\alpha_if_i$ convex for $\alpha_i\ge0$. *Ridge:* $\|X\theta-y\|^2+\lambda\|\theta\|^2$ is a sum of convex terms ($\lambda\ge0$).
- **Affine composition:** $f$ convex $\Rightarrow g(x)=f(Ax+b)$ convex. *Least squares:* the convex norm of the affine map $\theta\mapsto X\theta-y$.
- **Pointwise maximum:** $g=\max\{f_1,\dots,f_k\}$ convex. *SVM hinge loss:* $\max(0,\,1-y\,w^\top x)$, the maximum of two affine functions.

:::def Tests with derivatives
**First-order condition.** A differentiable $f$ is convex if and only if
$$
f(y)\ge f(x)+\nabla f(x)^\top(y-x)\qquad\text{for all }x,y\in\operatorname{dom}f :
$$
the function lies **above its tangent plane** at any point. (So if $\nabla f(x)=\mathbf 0$, then $f(y)\ge f(x)$ for every $y$: for a convex function a flat spot is a global minimum.)

**Second-order condition.** A twice-differentiable $f$ is convex if and only if its Hessian is PSD everywhere:
$$
\nabla^2f(x)\succeq0\quad\text{for all }x\in\operatorname{dom}f .
$$
If $\nabla^2f(x)\succ0$ (PD), $f$ is **strictly** convex. In 1-D: $f''(x)\ge0$ — the slope never decreases. "$\succeq0$" means $z^\top\nabla^2f(x)\,z\ge0$ for every $z$: the function curves up (or stays flat) in every direction. *Example:* $x^2+y^2$ has $\nabla^2f=2I\succ0$, strictly convex.
:::

**The least-squares loss is convex (slide p34).** $H_f(\theta)=X^\top X$, and for any direction $z$,
$$
z^\top(X^\top X)z=(Xz)^\top(Xz)=\|Xz\|^2\ge0,
$$
so $X^\top X\succeq0$ for every $\theta$ and the second-order condition holds. **Consequence: every minimum gradient descent reaches on a least-squares loss is the global minimum.** (The delivery Hessian has $\lambda=8.35,\ 0.15>0$: strictly convex, exactly one best line.)

:::example Problem Set 8, Problems 6–7 — convexity
:::orig [PSet 8 · Problems 6–7 ↗](pdfs/psets/PSet-08.pdf#page=1)
**P6.** Let $f(x)=\tfrac12x^\top Qx+c^\top x$ with $Q=\begin{pmatrix}2&1\\1&4\end{pmatrix}$ and $c=\begin{pmatrix}5\\3\end{pmatrix}$. (a) Compute the Hessian of $f$ and its eigenvalues. Is $f$ convex? (b) Find the minimiser $x^\ast$.

:::

Convex: the chord lies above the graph (equivalently the graph lies above every tangent, or $\nabla^2f\succeq0$); then every local minimum is global, and least squares ($H=X^\top X\succeq0$) is convex.

## 9. Gradient descent: walking downhill

:::note Not in this week's quiz
:::

:::figs
l09-p36|The optimisation problem: objective, inequality and equality constraints
l09-p37|Gradient descent: iterate in the direction of steepest descent
l09-p38|The update θᵢ ← θᵢ − α ∂L/∂θᵢ and the step size
l09-p40|The loop, and the effect of the step size on L(θ) = θ²
l09-p41|Linear regression with one feature: partial derivatives and the simultaneous update
l09-p42|Surface and contour plots of L(θ₀, θ₁)

:::

**Optimisation (slide p36)** means finding the optimal value of unknown variables under some constraints:
$$
\begin{aligned}
\text{minimise}\quad&f_0(\theta)\\
\text{subject to}\quad&f_i(\theta)\le0,\quad i=1,\dots,m,\\
&h_j(\theta)=0,\quad j=1,\dots,p,
\end{aligned}
$$
where $f_0$ is the **objective function** (e.g. $\tfrac12\|y-X\theta\|_2^2$), the $f_i$ are **inequality constraint** functions and the $h_j$ **equality constraint** functions. In ML, linear regression, neural networks and many other algorithms require solving such a problem; here we take **no constraints** and minimise $\mathcal L(\theta)$ over all $\theta\in\mathbb{R}^d$.

**Gradient descent (slide p37)** is the most commonly used method. It is best when the unknowns **cannot be determined analytically** and must be searched for numerically. It is iterative: start with reasonable coefficients (e.g. all zeros), then repeatedly update them in the direction of **steepest descent** until convergence.

**The update (slide p38).** Interpret $\partial\mathcal L/\partial\theta_i$ as the rate of change of the loss with respect to $\theta_i$: if $\partial\mathcal L/\partial\theta_i>0$, increasing $\theta_i$ increases $\mathcal L$ (so decrease $\theta_i$); if $<0$, increasing $\theta_i$ decreases $\mathcal L$ (so increase it). In both cases move **against the sign** of the derivative:

:::def Gradient descent
Initialise $\theta\in\mathbb{R}^d$ (e.g. zeros). Repeat until convergence:
$$
\theta_i\leftarrow\theta_i-\alpha\frac{\partial\mathcal L}{\partial\theta_i}\quad(i=1,\dots,d),\qquad\text{equivalently}\qquad \theta\leftarrow\theta-\alpha\nabla\mathcal L(\theta),\quad\alpha>0 .
$$
$\alpha$ is the **step size** or **learning rate**. **Simultaneous update:** compute every partial derivative at the current $\theta$ first, then change all parameters together. **Stop** when $\nabla\mathcal L(\theta)=\mathbf 0$ (in practice $\|\nabla\mathcal L\|<\varepsilon$), or when the loss barely changes between iterations.
:::

Why it works: $-\nabla\mathcal L$ is the steepest way down (§4), and the first-order Taylor map (§7) gives $\mathcal L(\theta-\alpha\nabla\mathcal L)\approx\mathcal L(\theta)-\alpha\|\nabla\mathcal L\|^2$ — a decrease whenever the gradient is non-zero, **provided $\alpha$ is small enough** for the map to be trusted.

### The step size

- **Too small $\alpha$:** gradient descent can be slow (typical constant values: 0.01, 0.05, 0.001; $\alpha$ can also be adapted each iteration).
- **Too large $\alpha$:** it can overshoot the minimum and fail to converge.

:::example $\mathcal L(\theta)=\theta^2$ from $\theta=2$ (slide p40, revision notes Figure 6)
$\mathcal L'=2\theta$, so one step gives $\theta\leftarrow\theta-2\alpha\theta=(1-2\alpha)\,\theta$.
- $\alpha=0.05$: factor $0.9$ — tiny steps, slow convergence.
- $\alpha=0.4$: factor $0.2$ — at the bottom in about three steps ($\alpha=0.5$ lands in one).
- $\alpha=1.05$: factor $-1.1$ — each jump overshoots further: **divergence**.

Convergence needs $|1-2\alpha|<1$, i.e. $0<\alpha<1$. In general a loss with curvature $\lambda$ in some direction needs $\alpha<2/\lambda$ there, so **$\alpha<2/\lambda_{\max}(H)$**, and the flattest direction ($\lambda_{\min}$) sets how slowly the last part of the walk goes.
:::

:::warn "Converges for a constant step size" — only if $\alpha$ is small enough
The slides say the algorithm converges for a constant rate "due to the automatic smaller step size near the optimal solution", and that each update makes the coefficients better. The steps do shrink near the minimum because the **gradient** shrinks, not because $\alpha$ does — but with $\alpha$ too large the loss goes **up** every step. For a quadratic loss the precise condition is $\alpha<2/\lambda_{\max}(H)$.
:::

### The linear-regression case (slides p41–43)

With half the MSE, one feature:
$$
\mathcal L(\theta_0,\theta_1)=\frac{1}{2n}\sum_{i=1}^n(\theta_0+\theta_1x_i-y_i)^2,\qquad
\frac{\partial\mathcal L}{\partial\theta_0}=\frac1n\sum_{i=1}^n(\theta_0+\theta_1x_i-y_i),\qquad
\frac{\partial\mathcal L}{\partial\theta_1}=\frac1n\sum_{i=1}^n(\theta_0+\theta_1x_i-y_i)\,x_i ,
$$
and the simultaneous update $\theta_0\leftarrow\theta_0-\alpha\,\partial\mathcal L/\partial\theta_0$, $\theta_1\leftarrow\theta_1-\alpha\,\partial\mathcal L/\partial\theta_1$. With $d$ features, $\mathcal L(\theta_0,\theta)=\frac{1}{2n}\sum_i(\theta_0+\theta^\top x_i-y_i)^2$, $\dfrac{\partial\mathcal L}{\partial\theta_j}=\dfrac1n\sum_i(\theta_0+\theta^\top x_i-y_i)\,x_i^{(j)}$ ($x_i^{(j)}$ = the $j$-th component of $x_i$), and
$$
\theta\leftarrow\theta-\frac{\alpha}{n}\sum_{i=1}^n(\theta_0+\theta^\top x_i-y_i)\,x_i .
$$

:::example Two steps on the delivery data, $\alpha=0.1$ (revision notes)
| step | $(\theta_0,\theta_1)$ | residuals $r_i=\theta_0+\theta_1x_i-y_i$ | $\nabla\mathcal L=(\bar r,\ \overline{rx})$ | $\mathcal L$ |
|---|---|---|---|---|
| 0 | $(0,\ 0)$ | $-13,\ -17,\ -23,\ -27$ | $(-20,\ -56)$ | 214.5 |
| 1 | $(2,\ 5.6)$ | $-5.4,\ -3.8,\ -4.2,\ -2.6$ | $(-4,\ -9)$ | 8.5 |
| 2 | $(2.4,\ 6.5)$ | | $(-1.35,\ -1.25)$ | 2.82 |

The loss collapses from 214.5 to 2.8 in two steps, yet $\theta_1=6.5$ has overshot the answer $4.8$ while $\theta_0=2.4$ is far from $8$ — the **ravine** of §6. With $\alpha=0.2$ the path zig-zags across the steep direction (factor $1-0.2(8.35)\approx-0.67$) and creeps along the flat one (factor $\approx0.97$): about 210 steps to get within 0.01. At $\alpha=0.24>2/8.35\approx0.2395$ it diverges. Centring the feature ($z_i=x_i-\bar x$) makes the Hessian $\operatorname{diag}(1,1.25)$, almost round: then $\alpha=0.8$ is safe and 5 steps suffice — why we **standardise features** before training.

*Simultaneous-update trap (Brainteaser 11):* updating $\theta_0=2$ first and using it in $\partial\mathcal L/\partial\theta_1$ gives $\theta_1=5.1$, not $5.6$ — a different algorithm.
:::

**Why use gradient descent when a closed form exists? (slide p44)** It is easier to implement, and computationally more efficient for large $d$: the closed form $(X^\top X)^{-1}X^\top y$ needs a $d\times d$ inversion, $\mathcal O(d^3)$, while each gradient-descent update costs $\mathcal O(nd)$, better when $d\gg1$. (A fair comparison is $(\text{number of steps})\times\mathcal O(nd)$ against $\mathcal O(nd^2+d^3)$ for forming and inverting $X^\top X$; and gradient descent also works for losses with **no** closed form.)

**P8.** Let $X\in\mathbb{R}^{N\times D}$, $y\in\mathbb{R}^N$, $\lambda>0$, and $\mathcal L(\theta)=\tfrac1N\|y-X\theta\|^2+\lambda\|\theta\|^2$. (a) Compute $\nabla\mathcal L(\theta)$. (b) Show that $\mathcal L$ is convex. (c) Write the gradient-descent update and give the closed-form minimiser.
**P9.** (a) For $\mathcal L(\theta)=\sum_{n=1}^N\mathcal L_n(\theta)$, write the SGD update with mini-batch size one. (b) For $N$ points in $D$ dimensions, compare the cost per update of batch GD and SGD. (c) For the quadratic of Problem 6, gradient descent is $x_{k+1}=x_k-\gamma(Qx_k+c)$. **P8.** (a) Using $\nabla\|X\theta-y\|^2=2X^\top(X\theta-y)$ and $\nabla\|\theta\|^2=2\theta$:
$$
\nabla\mathcal L(\theta)=\frac2NX^\top(X\theta-y)+2\lambda\theta .
$$
(b) $\nabla^2\mathcal L=\tfrac2NX^\top X+2\lambda I$, and $z^\top(\cdot)z=\tfrac2N\|Xz\|^2+2\lambda\|z\|^2>0$ for $z\neq\mathbf 0$: PD, so $\mathcal L$ is (strictly) convex. (c) $\theta\leftarrow\theta-\alpha\big[\tfrac2NX^\top(X\theta-y)+2\lambda\theta\big]$. Setting the gradient to zero: $(X^\top X+N\lambda I)\theta=X^\top y$, so $\theta^\ast=(X^\top X+N\lambda I)^{-1}X^\top y$ — ridge with penalty $N\lambda$.

**P9.** (a) Pick one index $n$ (at random) and update $\theta\leftarrow\theta-\alpha\nabla\mathcal L_n(\theta)$. (b) Batch: $\mathcal O(ND)$ per update; SGD: $\mathcal O(D)$. (c) $x_1=\mathbf 0-0.1(Q\mathbf 0+c)=-0.1c=(-0.5,\,-0.3)$. The iteration is $x_{k+1}-x^\ast=(I-\gamma Q)(x_k-x^\ast)$, which converges iff every eigenvalue $1-\gamma\lambda_i$ of $I-\gamma Q$ has $|1-\gamma\lambda_i|<1$, i.e.
$$
0<\gamma<\frac{2}{\lambda_{\max}(Q)}=\frac{2}{3+\sqrt2}\approx0.453 .
$$

:::remember
Gradient descent: $\theta\leftarrow\theta-\alpha\nabla\mathcal L(\theta)$ with a simultaneous update, stopping when $\|\nabla\mathcal L\|<\varepsilon$; it converges only if $\alpha<2/\lambda_{\max}(H)$, and a small $\lambda_{\min}$ (a ravine) makes it slow.

## 10. Stochastic and mini-batch gradient descent

**Batch (full) gradient descent (slide p44).** So far every step used all $n$ points; one sweep through the dataset is an **epoch**, and in batch GD one iteration is one epoch. Write the loss as an average of per-example losses (slide p45):
$$
\mathcal L(w)=\frac{1}{2n}\sum_{i=1}^n\big(\hat f(x_i,w)-y_i\big)^2=\frac1n\sum_{i=1}^ng(x_i,w,y_i),\qquad g(x_i,w,y_i)=\tfrac12\big(\hat f(x_i,w)-y_i\big)^2 ,
$$
where $g$ quantifies the prediction error for a single input. The batch update $w\leftarrow w-\alpha\frac1n\sum_{i=1}^n\nabla g(x_i,w,y_i)$ computes the gradient for **all $n$ points** — $n$ can be very large, so this is computationally expensive.

:::def Stochastic gradient descent (SGD)
At each iteration, update with **one** data point:
$$
w\leftarrow w-\alpha\,\nabla g(x_i,w,y_i).
$$
Also called **incremental** or **online** gradient descent; it approximates the batch update. **Choosing $i$:** *stochastic selection* draws it uniformly at random each iteration; *cyclic selection* uses $i=1,2,\dots,n,1,2,\dots$. Random selection (mostly used in practice) makes the update an **unbiased estimate** of the true gradient: $\mathbb E_i[\nabla g_i]=\frac1n\sum_i\nabla g_i=\nabla\mathcal L$.
:::

**SGD for linear regression (cyclic, slide p47).** Initialise $\theta_0\in\mathbb{R}$, $\theta\in\mathbb{R}^d$; repeat until convergence: for $i=1,\dots,n$,
$$
\theta_0\leftarrow\theta_0-\alpha(\theta_0+\theta^\top x_i-y_i),\qquad \theta\leftarrow\theta-\alpha(\theta_0+\theta^\top x_i-y_i)\,x_i .
$$
Each pass through the two lines is one **iteration**; the loop over all $i$ is one **epoch**. Even with cyclic selection, **shuffle the order after each epoch** — otherwise a fixed sequence of updates can cancel each other and hinder learning. For **online learning**, when data arrive in a stream and we must predict before having all points, we use SGD. (Delivery data from $(0,0)$, $\alpha=0.1$: order 1 alone, $r=-13$, gives the first SGD step $(1.3,\ 1.3)$ at a quarter of the cost of a batch step.)

**Pros of SGD (slide p46):** computationally efficient — the iteration cost is **independent of $n$**; the noisy gradient approximation can help **escape a poor local minimum**.

:::def Mini-batch SGD
From the $n$ points $\mathcal D$, randomly select a subset $\mathcal S\subseteq\mathcal D$ of $k\ll n$ points and update with their average gradient:
$$
w\leftarrow w-\alpha\,\frac1k\sum_{(x_i,y_i)\in\mathcal S}\nabla g(x_i,w,y_i).
$$
In one epoch, divide the data into $n/k$ mini-batches and step once per mini-batch.
:::

:::warn Divide by $k$, not $n$
The mini-batch slide writes the average with $\tfrac1n\sum_{i=1}^k$. The average over a mini-batch of $k$ points should be divided by **$k$**. Dividing by $n$ silently shrinks the step by a factor $k/n$: with $k=32$, $n=50{,}000$ and $\alpha=0.1$ the effective step is $6.4\times10^{-5}$, about 1500 times too small.
:::

| | batch GD | SGD | mini-batch SGD |
|---|---|---|---|
| points per update | $n$ | $1$ | $k\ll n$ |
| cost per update | $\mathcal O(nd)$ | $\mathcal O(d)$ | $\mathcal O(kd)$ |
| updates per epoch | $1$ | $n$ | $n/k$ |
| gradient estimate | exact | very noisy | mildly noisy |

Mini-batches trade a little noise for much cheaper updates and map well onto GPU hardware: a mini-batch is a small matrix, and GPUs multiply matrices in parallel, so processing $k$ examples costs little more time than one (deep networks use $k$ typically 32–512, with SGD variants such as Adam). *Example:* $n=10^6$, $d=100$: a batch update costs $\sim10^8$ multiply-adds, an SGD update $\sim10^2$; with $k=100$ there are $10^4$ updates per epoch.

:::remember
SGD steps with one random example ($\mathcal O(d)$, noisy but unbiased), mini-batch SGD with the average of $k$ ($\mathcal O(kd)$, divide by $k$), batch GD with all $n$ ($\mathcal O(nd)$, exact); an epoch is one pass over the data.
:::

## 11. Summary

**The thread:** derivatives show which way is downhill, convexity guarantees that downhill leads to the best answer, and gradient descent walks there.

| Tool | Definition | Key fact |
|---|---|---|
| derivative | $f'(x)=\lim_{\Delta x\to0}\frac{f(x+\Delta x)-f(x)}{\Delta x}$ | slope of the tangent; local |
| gradient | $\nabla f=[\partial f/\partial x_1,\dots,\partial f/\partial x_d]^\top$ | steepest ascent, ⟂ contours; $D_uf=\nabla f^\top u$ |
| common gradients | $\nabla a^\top x=a$, $\nabla x^\top Px=2Px$ ($P=P^\top$) | L05 |
| Jacobian | $J_{ij}=\partial f_i/\partial x_j$, $m\times n$ | $J_{Ax}=A$; $J_{f\circ g}=J_fJ_g$ |
| Hessian | $H_{jk}=\partial^2f/\partial x_j\partial x_k$ | eigenvalues: min / max / saddle; least squares $X^\top X$ |
| Taylor (2nd order) | $f(a)+\nabla f^\top(x-a)+\tfrac12(x-a)^\top H(x-a)$ | exact for quadratics |
| convex (definition) | $f(\theta x+(1-\theta)y)\le\theta f(x)+(1-\theta)f(y)$ | Jensen $f(\mathbb EX)\le\mathbb Ef(X)$ |
| convex (tests) | $f(y)\ge f(x)+\nabla f^\top(y-x)$; $\nabla^2f\succeq0$ | local min = global min |
| gradient descent | $\theta\leftarrow\theta-\alpha\nabla\mathcal L(\theta)$ | stop when $\|\nabla\mathcal L\|<\varepsilon$; $\alpha<2/\lambda_{\max}$ |
| SGD / mini-batch | $w\leftarrow w-\alpha\nabla g_i$; $w\leftarrow w-\frac\alpha k\sum_{i\in\mathcal S}\nabla g_i$ | $n/k$ updates per epoch |
