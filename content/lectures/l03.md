**What this lecture covers:** rank (definition, row rank = column rank, $\operatorname{rank}\le\min(m,n)$, key properties) → geometric meaning → rank and solvability of $Ax=b$ → computing rank by row reduction (REF/RREF) → column space $\mathcal C(A)$ → null space $\mathcal N(A)$ → rank–nullity theorem → the complete solution $x=x_p+x_n$ → the slide example. All linear-algebra working below is in matrix form.

:::intuition The paint-mixing machine (revision notes)
A machine holds three paint tubes, described by (R, G, B): red $a_1=(1,0,0)$, blue $a_2=(0,0,1)$, purple $a_3=(1,0,1)$. A recipe $x$ produces the colour
$$
Ax=x_1a_1+x_2a_2+x_3a_3,\qquad A=\begin{bmatrix}1&0&1\\0&0&0\\0&1&1\end{bmatrix}.
$$
**Q1** What colours can it make? → column space. **Q2** How many genuinely different paints does it have? (purple = red + blue) → rank. **Q3** Which recipes produce nothing? → null space. Yellow $(1,1,0)$ is impossible (every column has green = 0), and the recipe $(1,1,-1)$ produces $0$.
:::

## 1. Rank

:::def Rank (slide definition)
The **rank** of $A$ is the minimum of the number of linearly independent rows and the number of linearly independent columns.
- **Row rank**: maximum number of linearly independent rows.
- **Column rank**: maximum number of linearly independent columns.
:::

:::thm Row rank = column rank
For every matrix the two numbers are **equal**; their common value is $\operatorname{rank}(A)$. (So the "minimum" in the slide definition is never a real contest.) Consequently
$$
\operatorname{rank}(A)\le\min(m,n)\qquad(A\in\mathbb{R}^{m\times n}).
$$
:::

:::proof Why (pivot argument)
Reduce $A$ to echelon form. Each pivot occupies its own row and its own column. The non-zero rows (one per pivot) are independent ⇒ row rank = #pivots. The pivot columns are independent and every non-pivot column is a combination of them ⇒ column rank = #pivots. Row operations do not change which column combinations give zero, so this carries back to $A$. Hence both equal the number of pivots. The bound: you cannot have more independent columns than columns ($\le n$), nor more independent vectors in $\mathbb{R}^m$ than $m$ ($\le m$) — "rank is limited by whichever runs out first, ingredients or room".
:::

### Key properties (slide p3)

1. $\operatorname{rank}(A)=\operatorname{rank}(A^\top)$ — rows and columns hold the same amount of independent information.
2. $\operatorname{rank}(AB)\le\min(\operatorname{rank}A,\operatorname{rank}B)$ — "a pipeline is only as wide as its narrowest pipe".
3. If $A\in\mathbb{R}^{n\times n}$ is invertible, $\operatorname{rank}(A)=n$ (full rank) — an invertible map flattens no direction.

:::proof Property 2 (PSet 4, P4)
**Column space.** Column $j$ of $AB$ is $Ab_j=b_{1j}a_1+\dots+b_{nj}a_n$ — a combination of the columns of $A$. So $\mathcal C(AB)\subseteq\mathcal C(A)$ and $\operatorname{rank}(AB)\le\operatorname{rank}(A)$.
**Null space.** If $Bx=0$ then $ABx=0$, so $\mathcal N(B)\subseteq\mathcal N(AB)$, hence $\operatorname{nullity}(AB)\ge\operatorname{nullity}(B)$. Both have $p$ columns, so by rank–nullity $\operatorname{rank}(AB)=p-\operatorname{nullity}(AB)\le p-\operatorname{nullity}(B)=\operatorname{rank}(B)$.
**Strict example**: $A=B=\begin{pmatrix}0&1\\0&0\end{pmatrix}$ each have rank 1 but $AB=0$ has rank 0.
2026 Quiz 5 (iii): "rank of $AB$ can be strictly greater than rank of $A$" — **False**.
:::

Other facts used in exams:

- A non-zero **outer product** $uv^\top$ ($u\in\mathbb{R}^5,v\in\mathbb{R}^4$) is $5\times4$ with rank exactly 1 (product of a $5\times1$ and a $1\times4$, so rank $\le1$). It stores 20 numbers but needs only $5+4=9$ — the seed of low-rank compression.
- **Full column rank**: $\operatorname{rank}=n$ (every column new). **Full row rank**: $\operatorname{rank}=m$. **Rank deficient**: $\operatorname{rank}<\min(m,n)$.
- Duplicating a feature: $X\in\mathbb{R}^{1000\times50}$ with column 50 = column 1 ⇒ $\operatorname{rank}X\le49$ ⇒ $X^\top X$ singular.
- $\operatorname{rank}(A^\top A)=\operatorname{rank}(A)$ (they have the same null space, by the Gram-matrix argument of L02).

:::remember
Rank = number of genuinely independent columns = number of independent rows = number of pivots $\le\min(m,n)$.
:::

## 2. Geometric interpretation

**Rank is the dimension of the space spanned by the columns of $A$.** For a $3\times3$ matrix:

| Rank | Columns… | Picture |
|---|---|---|
| 3 | span $\mathbb{R}^3$ | a solid **volume** |
| 2 | lie on a **plane** through 0 | flat sheet |
| 1 | lie on a **line** through 0 | |
| 0 | are all zero | the origin only |

Equivalently (3Blue1Brown), rank is the number of dimensions left after the matrix squishes space.

:::example Rank by inspection (revision brainteaser)
$B_1=\begin{bmatrix}2&4&-6\\1&2&-3\\-3&-6&9\end{bmatrix}$: every row is a multiple of $(2,4,-6)$ ⇒ rank 1 (line).
$B_2=I_3$ ⇒ rank 3 (volume). $B_3=\begin{bmatrix}1&0&1\\0&1&1\\0&0&0\end{bmatrix}$: column 3 = col 1 + col 2 ⇒ rank 2 (plane). $B_4=0$ ⇒ rank 0.
2025 Quiz 3: $\begin{bmatrix}1&2&3\\2&4&6\\1&1&1\end{bmatrix}$ — row 2 = 2·row 1, row 3 not a multiple ⇒ rank 2 ⇒ columns dependent, column space is a plane in $\mathbb{R}^3$.
:::

:::remember
Rank 3 / 2 / 1 for a $3\times3$ matrix means the columns fill a volume / a plane / a line.
:::

## 3. Computing rank by row reduction

The reliable method is **Gaussian elimination** to **Row Echelon Form (REF)** or **Reduced Row Echelon Form (RREF)**; the number of non-zero rows in REF (= pivots in RREF) is the rank.

**Recipe (slide p6):** (1) write the augmented or coefficient matrix; (2) apply Gaussian elimination to reach REF or RREF; (3) count the non-zero rows (pivots) — that number is the rank.

**Elementary row operations** — they never change rank, row space or null space: swap two rows; multiply a row by a non-zero scalar; add a multiple of one row to another. (They reorganise the evidence; a row that was secretly a combination of others becomes a row of zeros.)

**REF**: all zero rows at the bottom; each row's first non-zero entry (the **pivot**) is to the right of the pivot above. **RREF**: additionally every pivot is 1 and is the only non-zero entry in its column.

:::example Slide example
$$
\begin{bmatrix}1&2&3\\2&4&6\\1&1&1\end{bmatrix}
\xrightarrow[R_3-R_1]{R_2-2R_1}
\begin{bmatrix}1&2&3\\0&0&0\\0&-1&-2\end{bmatrix}
\xrightarrow[R_2\leftarrow -R_2]{\text{swap }R_2,R_3}
\begin{bmatrix}1&2&3\\0&1&2\\0&0&0\end{bmatrix}
\quad\Rightarrow\quad\operatorname{rank}=2 .
$$
Going on to RREF ($R_1-2R_2$):
$$
\operatorname{rref}(A)=\begin{bmatrix}1&0&-1\\0&1&2\\0&0&0\end{bmatrix}\ \Rightarrow\ a_3=-1\cdot a_1+2\cdot a_2 .
$$
Check: $-\begin{bmatrix}1\\2\\1\end{bmatrix}+2\begin{bmatrix}2\\4\\1\end{bmatrix}=\begin{bmatrix}3\\6\\1\end{bmatrix}$ ✓. **The RREF reads out the recipe for each redundant column.**
:::

:::remember
Eliminate to echelon form and count pivots; RREF also tells you exactly how the non-pivot columns depend on the pivot columns.
:::

## 4. Column space

:::def Column space
For $A\in\mathbb{R}^{m\times n}$ with columns $a_1,\dots,a_n\in\mathbb{R}^m$:
$$
\mathcal C(A)=\operatorname{span}(a_1,\dots,a_n)=\{Ax\mid x\in\mathbb{R}^n\}
$$
— all possible linear combinations of the columns = everything the map $x\mapsto Ax$ can output (also called the **range**).
:::

- $\mathcal C(A)$ is a **subspace of $\mathbb{R}^m$** (the output space): $Ax+Ay=A(x+y)$, $cAx=A(cx)$, and $A0=0$.
- $\dim\mathcal C(A)$ = number of linearly independent columns = $\operatorname{rank}(A)$.
- A **basis** for $\mathcal C(A)$: the **pivot columns of the original $A$** (not of the echelon form).
- Paint shop: $\mathcal C(A)=\operatorname{span}\{(1,0,0),(0,0,1)\}=\{(r,0,b)\}$ — the red–blue plane; yellow is off the menu.

:::thm Solvability
$$
Ax=b\text{ has a solution}\iff b\in\mathcal C(A)\iff\operatorname{rank}(A)=\operatorname{rank}\big([A\mid b]\big).
$$
(If appending $b$ raises the rank, $b$ was a new direction — off the menu.)
:::

:::example Revision brainteaser — on the menu?
$A=\begin{bmatrix}1&1&2\\2&1&3\\3&1&4\\4&1&5\end{bmatrix}$ (column 3 = col 1 + col 2, so $\mathcal C(A)$ is a plane in $\mathbb{R}^4$).
(a) $b=(1,1,1,1)$ = column 2 ⇒ yes, $x=(0,1,0)$.
(b) $b=(3,5,7,9)$ = col 1 + col 3 ⇒ yes, $x=(1,0,1)$ (also $(2,1,0)$ — many recipes, because $\mathcal N(A)\neq\{0\}$).
(c) $b=(0,0,0,1)$: $x_1a_1+x_2a_2$ has entries $x_1+x_2,\,2x_1+x_2,\dots$; the first two being 0 forces $x_1=x_2=0$, but then entry 4 is $0\neq1$ ⇒ **no**.
:::

:::remember
$\mathcal C(A)\subseteq\mathbb{R}^m$ is the set of reachable outputs; $Ax=b$ is solvable exactly when $b$ is in it.
:::

## 5. Null space

:::def Null space
$$
\mathcal N(A)=\{x\in\mathbb{R}^n\mid Ax=0\}
$$
— all points mapped to zero by $A$ (the "inverse image" of $0\in\mathbb{R}^m$). It is a **subspace of $\mathbb{R}^n$** (the input space). Its dimension is the **nullity** of $A$.
:::

Pictures: a lamp shining straight down maps $\mathbb{R}^3\to\mathbb{R}^2$ (shadow), $A=\begin{pmatrix}1&0&0\\0&1&0\end{pmatrix}$; sliding an object vertically doesn't move its shadow, so $\mathcal N(A)$ is the vertical axis. $M=\begin{pmatrix}1&2\\2&4\end{pmatrix}$ squashes the plane onto the line through $(1,2)$; $\mathcal N(M)=\operatorname{span}\{(2,-1)\}$ collapses to the origin.

**Null-space vectors are recipes for redundancy**: each $x\in\mathcal N(A)$ records how the columns cancel, $\sum x_ja_j=0$. Independent columns ⇔ $\mathcal N(A)=\{0\}$ (2026 Quiz 5 (ii): $Ax=0$ only trivially ⇒ rank exactly $n$ — **True**). If $Ax=0$ for some non-zero $x$, the **columns** of $A$ are dependent (2024 Mid MCQ 18 — not necessarily the rows, and $A\neq0$ need not hold).

### Computing a null space: free variables and special solutions

1. Reduce $A$ to (R)REF.
2. **Pivot variables** ↔ pivot columns; **free variables** ↔ non-pivot columns.
3. For each free variable, set it to 1 and the other free variables to 0, solve for the pivot variables → one **special solution**.
4. The special solutions form a basis of $\mathcal N(A)$; their number = number of free variables = $n-r$.

:::example Slide rank example
From $\operatorname{rref}(A)=\begin{bmatrix}1&0&-1\\0&1&2\\0&0&0\end{bmatrix}$, $x_3$ is free. $x_3=1$ gives
$$
x=x_3\begin{bmatrix}1\\-2\\1\end{bmatrix},\qquad \mathcal N(A)=\operatorname{span}\left\{\begin{bmatrix}1\\-2\\1\end{bmatrix}\right\}.
$$
Matches the column relation $a_1-2a_2+a_3=0$. For the $4\times3$ slide example ($a_3=a_1+a_2$): $\mathcal N(A)=\operatorname{span}\{(1,1,-1)\}$, a line in $\mathbb{R}^3$.
:::

:::example Worksheet 2, Problem 1
$$
A=\begin{bmatrix}1&2&1\\-2&-3&1\\3&5&0\end{bmatrix}\xrightarrow[R_3-3R_1]{R_2+2R_1}\begin{bmatrix}1&2&1\\0&1&3\\0&-1&-3\end{bmatrix}\xrightarrow{R_3+R_2}\begin{bmatrix}1&2&1\\0&1&3\\0&0&0\end{bmatrix}.
$$
Rank 2. Basis of $\mathcal C(A)$: original pivot columns $\{(1,-2,3),(2,-3,5)\}$ — a plane through 0 in $\mathbb{R}^3$. Null space: $x_3$ free, $x_2=-3x_3$, $x_1=-2x_2-x_3=5x_3$ ⇒ $\mathcal N(A)=\operatorname{span}\{(5,-3,1)\}$. Check: $A(5,-3,1)^\top=(5-6+1,\,-10+9+1,\,15-15)=0$ ✓. Rank–nullity: $2+1=3$ ✓.
:::

:::remember
$\mathcal N(A)\subseteq\mathbb{R}^n$ = inputs the machine forgets; one special solution per free variable gives its basis.
:::

## 6. The rank–nullity theorem

:::thm Rank–nullity (rank + nullity) theorem
For $A\in\mathbb{R}^{m\times n}$:
$$
\operatorname{rank}(A)+\operatorname{nullity}(A)=n=\text{number of columns of }A,
\qquad\text{i.e.}\qquad \dim\mathcal C(A)+\dim\mathcal N(A)=n .
$$
:::

**Why ("conservation of dimensions")**: you start with $n$ input knobs. Each input dimension either **survives** as a new output direction (counted by the rank = pivot columns) or is **crushed** to 0 (counted by the nullity = free columns). Pivots + free = $n$.

| Matrix | $n$ | rank | nullity | check |
|---|---|---|---|---|
| paint shop $3\times3$ | 3 | 2 | 1 | ✓ |
| $\begin{bmatrix}1&2&3\\2&4&6\\1&1&1\end{bmatrix}$ | 3 | 2 | 1 | ✓ |
| slide $4\times3$ | 3 | 2 | 1 | ✓ |
| $\begin{pmatrix}1&2\\2&4\end{pmatrix}$ | 2 | 1 | 1 | ✓ |
| shadow $\begin{pmatrix}1&0&0\\0&1&0\end{pmatrix}$ | 3 | 2 | 1 | ✓ |

:::warn Count columns, not rows
The theorem counts $n$ (columns). For the $4\times3$ slide example rank + nullity $=3$, not 4. And remember where each space lives: $\mathcal N(A)\subseteq\mathbb{R}^n$ (inputs), $\mathcal C(A)\subseteq\mathbb{R}^m$ (outputs) — you cannot compare them unless $m=n$.
:::

:::example 2025 Mid, Problem 6
$A\in\mathbb{R}^{5\times7}$, rank 4. (a) $\dim\mathcal C(A)=4$. (b) $\dim\mathcal N(A)=7-4=3$. (c) Is $Ax=b$ solvable for every $b\in\mathbb{R}^5$? **No**: $\mathcal C(A)$ is a 4-dimensional proper subspace of $\mathbb{R}^5$; only $b\in\mathcal C(A)$ are reachable (we'd need rank 5).
Revision: $W\in\mathbb{R}^{3\times7}$ rank 3 ⇒ nullity 4 and $\mathcal C(W)=\mathbb{R}^3$. A $7\times3$ matrix *can* have trivial null space (rank 3); a $3\times7$ matrix never can (nullity $\ge4$) — **a wide matrix always forgets something**.
:::

:::example Construct or prove impossible (PSet 4, P3)
(a) Column space contains $(1,1,0),(0,0,1)$ and row space contains $(1,2),(2,5)$: need $3\times2$ of rank 2, e.g. $\begin{pmatrix}1&0\\1&0\\0&1\end{pmatrix}$ ✓.
(b) Column-space basis $\{(1,1,3)\}$ and null-space basis $\{(3,1,1)\}$: $m=3$, $r=1$, $n=3$, nullity 1 ⇒ $1+1\neq3$ — **impossible**.
(c) $\dim\mathcal N(A)=1+\dim\mathcal N(A^\top)$: $n-r=1+(m-r)$ ⇒ $n=m+1$, e.g. $A=(1\ \ 0)$ ✓. (Here $\mathcal N(A^\top)$, the **left null space**, lives in $\mathbb{R}^m$ and has dimension $m-r$; the **row space** $\mathcal C(A^\top)$ has dimension $r$.)
:::

:::remember
rank + nullity = $n$ (columns): every input dimension is either kept (rank) or crushed (nullity).
:::

## 7. Rank and linear systems; the complete solution

**Existence is a column-space question** ($b\in\mathcal C(A)$?). **Uniqueness is a null-space question**: if $x_p$ solves $Ax=b$ then so does $x_p+z$ for every $z\in\mathcal N(A)$, since $A(x_p+z)=b+0=b$.
$$
\{\text{all solutions of }Ax=b\}=x_p+\mathcal N(A)\qquad(\text{particular solution + any null-space vector}).
$$

The slide (p5) states, for $Ax=b$: rank $=n$ ⇒ unique; rank $<n$ ⇒ infinitely many; rank $<m$ ⇒ inconsistent. These are **shorthand**; the precise versions:

| Slide says | Precisely |
|---|---|
| $\operatorname{rank}A=n$ ⇒ unique solution | $\mathcal N(A)=\{0\}$ ⇒ **at most one** solution; exactly one if $b\in\mathcal C(A)$ |
| $\operatorname{rank}A<n$ ⇒ infinitely many | $\mathcal N(A)$ non-trivial ⇒ **if** a solution exists there are infinitely many (else 0) |
| $\operatorname{rank}A<m$ ⇒ inconsistent | $\mathcal C(A)\neq\mathbb{R}^m$ ⇒ **some** $b$ are unreachable; others may still be reachable |

**The four cases** (PSet 4, P2) — memorise:

| Case | Shape | $\mathcal C(A)$ | Solutions of $Ax=b$ | Example |
|---|---|---|---|---|
| $r=m=n$ | square, invertible | all $\mathbb{R}^m$ | exactly 1, every $b$ | $\begin{pmatrix}1&2\\3&1\end{pmatrix}$ |
| $r=n<m$ | tall, full column rank | a slice | 0 or 1 | $\begin{pmatrix}1&0\\0&1\\0&0\end{pmatrix}$ |
| $r=m<n$ | wide, full row rank | all $\mathbb{R}^m$ | $\infty$, every $b$ | $\begin{pmatrix}1&0&1\\0&1&1\end{pmatrix}$ |
| $r<m,\ r<n$ | rank deficient | a slice | 0 or $\infty$ | PSet 4 P1 below |

:::example PSet 4, Problem 1 — complete solution in matrix form
$$
[A\mid b]=\left[\begin{array}{cccc|c}1&2&2&2&b_1\\2&4&6&8&b_2\\3&6&8&10&b_3\end{array}\right]
\xrightarrow[R_3-3R_1]{R_2-2R_1}
\left[\begin{array}{cccc|c}1&2&2&2&b_1\\0&0&2&4&b_2-2b_1\\0&0&2&4&b_3-3b_1\end{array}\right]
\xrightarrow{R_3-R_2}
\left[\begin{array}{cccc|c}1&2&2&2&b_1\\0&0&2&4&b_2-2b_1\\0&0&0&0&b_3-b_2-b_1\end{array}\right].
$$
**Rank** 2 (pivots in columns 1, 3); free variables $x_2,x_4$.
**Solvability**: need $b_3-b_2-b_1=0$, i.e. $\mathcal C(A)$ is the plane $b_1+b_2-b_3=0$ in $\mathbb{R}^3$.
**Special solutions**: $(x_2,x_4)=(1,0)$ ⇒ $s_1=\begin{bmatrix}-2\\1\\0\\0\end{bmatrix}$; $(x_2,x_4)=(0,1)$ ⇒ $s_2=\begin{bmatrix}2\\0\\-2\\1\end{bmatrix}$; $\dim\mathcal N(A)=4-2=2$.
**Particular solution** for $b=(1,5,6)$ (valid since $1+5=6$): free variables $=0$ gives $2x_3=3$, $x_1+2x_3=1$ ⇒ $x_p=\begin{bmatrix}-2\\0\\3/2\\0\end{bmatrix}$.
$$
x=\begin{bmatrix}-2\\0\\3/2\\0\end{bmatrix}+c_1\begin{bmatrix}-2\\1\\0\\0\end{bmatrix}+c_2\begin{bmatrix}2\\0\\-2\\1\end{bmatrix},\quad c_1,c_2\in\mathbb{R}.
$$
For $b=(1,5,7)$ there is **no** solution although $r<n$ — so the correct statement is "if $r<n$ there are **0 or infinitely many** solutions".
:::

:::example $M=\begin{pmatrix}1&2\\2&4\end{pmatrix}$
$Mx=(3,6)$: $(3,6)=3(1,2)$ is on the line $\mathcal C(M)$; $x=\begin{bmatrix}3\\0\end{bmatrix}+t\begin{bmatrix}2\\-1\end{bmatrix}$ — a line parallel to $\mathcal N(M)$. $Mx=(3,5)$: not on the line ($5\neq2\cdot3$) ⇒ no solution.
Paint shop: colour $(1,0,1)$ = $(1,1,0)$ recipe = $(0,0,1)$ recipe = $(1,1,0)+t(-1,-1,1)$ — infinitely many recipes because of the ghost direction.
:::

:::remember
Solutions of $Ax=b$ = one particular solution + the whole null space; existence ⇔ $b\in\mathcal C(A)$, uniqueness ⇔ $\mathcal N(A)=\{0\}$.
:::

## 8. Slide example and AI connections

:::example Slide p10
$$
A=\begin{bmatrix}1&1&2\\2&1&3\\3&1&4\\4&1&5\end{bmatrix},\quad m=4,\ n=3 .
$$
$\mathcal C(A)$ is a subspace of $\mathbb{R}^4$; $\mathcal N(A)$ is a subspace of $\mathbb{R}^3$. Column 3 = column 1 + column 2, so exactly 2 columns are independent ⇒ $\mathcal C(A)$ is a **2-dimensional subspace of $\mathbb{R}^4$**, and by rank–nullity $\dim\mathcal N(A)=1$ with $\mathcal N(A)=\operatorname{span}\{(1,1,-1)\}$.
:::

:::ml Why an ML student should care
- **Regression is a column-space problem.** Predictions $X\theta$ always lie in $\mathcal C(X)$. With many more samples than features ($n\gg d$), $\mathcal C(X)$ is a thin slice of $\mathbb{R}^n$ and $y$ is almost never on it — we choose the closest reachable point: **least squares** (L05).
- **Redundant features create a null space.** Height in cm and in inches ⇒ dependent columns ⇒ $\theta$ and $\theta+tz$ ($z\in\mathcal N(X)$) give identical predictions; the model cannot split credit. Fix: drop duplicates or regularise (ridge, L05). This is the 2024 Mid multicollinearity problem.
- **Compression uses low rank.** A rank-$r$ matrix is stored with far fewer numbers (outer products) — returns with SVD, PCA, low-rank fine-tuning.
:::

:::exam How this lecture has been examined
- **2026 Quiz 5 Q1**: T/F with justification — $m>n$ ⇒ $\mathcal C(A)$ can't span $\mathbb{R}^m$ (true that it **can't**; the statement "can span" is False); $Ax=0$ only trivial ⇒ rank $n$ (True); $\operatorname{rank}(AB)>\operatorname{rank}(A)$ possible (False).
- **2025 Quiz 3**: rank of a $3\times3$ and what it means for the columns and column space.
- **Mid MCQ**: rank + nullity $=n$ (T), $\operatorname{rank}A=\operatorname{rank}A^\top$ (T), "rank equals number of rows" (F), "rank $=m$ ⇒ columns independent" (F); $4\times3$ of rank 3 ⇒ independent columns, $\mathcal N=\{0\}$, row space dim 3, $\dim\mathcal C=3$ (all T).
- **Mid problem**: $5\times7$ rank 4 — dims of $\mathcal C$, $\mathcal N$, solvable for all $b$?
:::

:::remember The one line for this lecture
A matrix reaches exactly its column space ($\dim=\operatorname{rank}$) and forgets exactly its null space ($\dim=n-\operatorname{rank}$); $Ax=b$ is solvable iff $b\in\mathcal C(A)$, and then every solution is $x_p+\mathcal N(A)$.
:::
