This lecture asks three questions about a matrix $A$: what it can produce, how many genuinely different things it can produce, and which inputs it makes invisible. The answers are the **column space**, the **rank** and the **null space**. In order, the notes cover: the definition and properties of rank; its geometric meaning; computing rank by row reduction; the column space and the solvability of $Ax=b$; the null space and how to compute it; the rank–nullity theorem; the complete solution $x=x_p+x_n$; and the slide's example together with the connections to machine learning. All linear-algebra working is written in matrix form.

:::intuition The paint-mixing machine (revision notes)
A machine holds three tubes of paint, each described by its (red, green, blue) content: red $a_1=(1,0,0)$, blue $a_2=(0,0,1)$ and purple $a_3=(1,0,1)$. A recipe $x$ produces the colour
$$
Ax=x_1a_1+x_2a_2+x_3a_3,\qquad A=\begin{bmatrix}1&0&1\\0&0&0\\0&1&1\end{bmatrix}.
$$
**Q1.** Which colours can it make? This is the column space. **Q2.** How many genuinely different paints does it hold? Purple is red plus blue, so only two — this is the rank. **Q3.** Which recipes produce nothing? This is the null space. Yellow $(1,1,0)$ is impossible, because every tube has green content $0$; and the recipe $x=(1,1,-1)$ produces $Ax=\mathbf 0$.
:::

## 1. Rank

:::def Rank (slide definition)
The **rank** of $A$ is the minimum of the number of linearly independent rows and the number of linearly independent columns of $A$.

- The **row rank** is the maximum number of linearly independent rows.
- The **column rank** is the maximum number of linearly independent columns.
:::

:::thm Row rank equals column rank
For every matrix the row rank and the column rank are **equal**; their common value is $\operatorname{rank}(A)$. (So the "minimum" in the slide's definition is never a real contest.) As a consequence,
$$
\operatorname{rank}(A)\le\min(m,n)\qquad\text{for every }A\in\mathbb{R}^{m\times n}.
$$
:::

:::proof Why the two ranks agree
Reduce $A$ to echelon form. Each pivot occupies its own row and its own column. The non-zero rows, one per pivot, are independent, so the row rank equals the number of pivots. The pivot columns are independent and every other column is a combination of them, so the column rank also equals the number of pivots. Row operations do not change which combinations of columns vanish, so the conclusion carries back to $A$ itself.

The bound $\operatorname{rank}(A)\le\min(m,n)$ holds because there cannot be more independent columns than there are columns ($n$), nor more independent vectors in $\mathbb{R}^m$ than $m$. In the revision notes' words, rank is limited by whichever runs out first — ingredients or room.
:::

### Key properties (slide p3)

1. $\operatorname{rank}(A)=\operatorname{rank}(A^\top)$: the rows and the columns carry the same amount of independent information.
2. $\operatorname{rank}(AB)\le\min\big(\operatorname{rank}A,\ \operatorname{rank}B\big)$: a pipeline is only as wide as its narrowest pipe.
3. If $A\in\mathbb{R}^{n\times n}$ is invertible, then $\operatorname{rank}(A)=n$: an invertible map flattens no direction.

:::proof Property 2 (PSet 4, Problem 4)
**The column space shrinks.** Column $j$ of $AB$ is
$$
Ab_j=b_{1j}a_1+b_{2j}a_2+\cdots+b_{nj}a_n ,
$$
a combination of the columns of $A$. Hence $\mathcal C(AB)\subseteq\mathcal C(A)$, and so $\operatorname{rank}(AB)\le\operatorname{rank}(A)$.

**The null space grows.** If $Bx=\mathbf 0$ then $ABx=\mathbf 0$, so $\mathcal N(B)\subseteq\mathcal N(AB)$ and $\operatorname{nullity}(AB)\ge\operatorname{nullity}(B)$. Both matrices have $p$ columns, so by the rank–nullity theorem (§6)
$$
\operatorname{rank}(AB)=p-\operatorname{nullity}(AB)\le p-\operatorname{nullity}(B)=\operatorname{rank}(B).
$$
**The inequality can be strict.** For $A=B=\begin{pmatrix}0&1\\0&0\end{pmatrix}$ each matrix has rank $1$, but $AB=0$ has rank $0$. (In 2026 Quiz 5, the statement "the rank of $AB$ can be strictly greater than the rank of $A$" is therefore false.)
:::

Other facts that appear in exams:

- A non-zero **outer product** $uv^\top$, with $u\in\mathbb{R}^5$ and $v\in\mathbb{R}^4$, is a $5\times4$ matrix of rank exactly $1$, since it is the product of a $5\times1$ and a $1\times4$ matrix. It holds $20$ numbers but is described by only $5+4=9$, which is the seed of low-rank compression.
- **Full column rank** means $\operatorname{rank}A=n$, so that every column is new; **full row rank** means $\operatorname{rank}A=m$; a matrix is **rank-deficient** if $\operatorname{rank}A<\min(m,n)$.
- Duplicating a feature reduces the rank: if $X\in\mathbb{R}^{1000\times50}$ has column $50$ equal to column $1$, then $\operatorname{rank}X\le49$ and $X^\top X$ is singular.
- $\operatorname{rank}(A^\top A)=\operatorname{rank}(A)$, because the two matrices have the same null space (by the Gram-matrix argument of L02).

:::remember
The rank is the number of genuinely independent columns, which equals the number of independent rows and the number of pivots, and it never exceeds $\min(m,n)$.
:::

## 2. Geometric interpretation

:::figs
l03-p04|Rank as the dimension spanned by the columns
:::

**The rank is the dimension of the space spanned by the columns of $A$.** For a $3\times3$ matrix:

| Rank | The columns … | Picture |
|---|---|---|
| $3$ | span all of $\mathbb{R}^3$ | a solid volume |
| $2$ | lie in a plane through $\mathbf 0$ | a flat sheet |
| $1$ | lie on a line through $\mathbf 0$ | a line |
| $0$ | are all zero | the origin alone |

Equivalently (in the language of 3Blue1Brown), the rank is the number of dimensions that remain after the matrix squashes space.

:::example Reading the rank without elimination (revision notes)
$$
B_1=\begin{bmatrix}2&4&-6\\1&2&-3\\-3&-6&9\end{bmatrix},\quad
B_2=I_3,\quad
B_3=\begin{bmatrix}1&0&1\\0&1&1\\0&0&0\end{bmatrix},\quad
B_4=\begin{bmatrix}0&0\\0&0\end{bmatrix}.
$$
Every row of $B_1$ is a multiple of $(2,4,-6)$, so $\operatorname{rank}B_1=1$: a line. The identity has rank $3$: a volume. In $B_3$, column 3 equals column 1 plus column 2, and the first two columns are independent, so $\operatorname{rank}B_3=2$: a plane. Finally $\operatorname{rank}B_4=0$.

In 2025 Quiz 3, the matrix $\begin{bmatrix}1&2&3\\2&4&6\\1&1&1\end{bmatrix}$ has row 2 equal to twice row 1, while row 3 is not a multiple of row 1. Its rank is therefore $2$, its columns are dependent, and its column space is a plane in $\mathbb{R}^3$.
:::

:::remember
For a $3\times3$ matrix, rank $3$, $2$ or $1$ means that the columns fill a volume, a plane or a line.
:::

## 3. Computing rank by row reduction

The reliable method is **Gaussian elimination** to **row echelon form (REF)** or **reduced row echelon form (RREF)**. The number of non-zero rows of the echelon form — equivalently, the number of pivots — is the rank.

**The recipe (slide p6).** (1) Write down the coefficient matrix (or the augmented matrix). (2) Apply Gaussian elimination until the matrix is in REF or RREF. (3) Count the non-zero rows; that number is the rank.

**Elementary row operations** are: exchanging two rows; multiplying a row by a non-zero scalar; and adding a multiple of one row to another. None of them changes the rank, the row space or the null space. They reorganise the evidence without creating or destroying any, so a row that was secretly a combination of the others becomes a row of zeros.

In **REF**, every zero row is at the bottom and the first non-zero entry of each row (its **pivot**) lies to the right of the pivot in the row above. In **RREF**, in addition, every pivot equals $1$ and is the only non-zero entry in its column.

:::example The slide example
$$
\begin{bmatrix}1&2&3\\2&4&6\\1&1&1\end{bmatrix}
\xrightarrow[\;R_3\,\leftarrow\,R_3-R_1\;]{\;R_2\,\leftarrow\,R_2-2R_1\;}
\begin{bmatrix}1&2&3\\0&0&0\\0&-1&-2\end{bmatrix}
\xrightarrow[\;R_2\,\leftarrow\,-R_2\;]{\;R_2\,\leftrightarrow\,R_3\;}
\begin{bmatrix}1&2&3\\0&1&2\\0&0&0\end{bmatrix}.
$$
There are two non-zero rows, so $\operatorname{rank}=2$. Continuing to RREF with $R_1\leftarrow R_1-2R_2$,
$$
\operatorname{rref}(A)=\begin{bmatrix}1&0&-1\\0&1&2\\0&0&0\end{bmatrix},
$$
which tells us that column 3 is $-1$ times column 1 plus $2$ times column 2. Checking this against the original matrix,
$$
-1\begin{bmatrix}1\\2\\1\end{bmatrix}+2\begin{bmatrix}2\\4\\1\end{bmatrix}=\begin{bmatrix}3\\6\\1\end{bmatrix}.
$$
**The RREF reads out the recipe for every redundant column.**
:::

:::remember
Eliminate to echelon form and count the pivots; the RREF also shows exactly how each non-pivot column depends on the pivot columns.
:::

## 4. Column space

:::figs
l03-p08|Column space
:::

:::def Column space
For $A\in\mathbb{R}^{m\times n}$ with columns $a_1,\dots,a_n\in\mathbb{R}^m$, the **column space** (or **range**) of $A$ is
$$
\mathcal C(A)=\operatorname{span}(a_1,\dots,a_n)=\{\,Ax\ :\ x\in\mathbb{R}^n\,\}.
$$
It consists of all possible linear combinations of the columns, which is the same as everything the map $x\mapsto Ax$ can output.
:::

- $\mathcal C(A)$ is a **subspace of $\mathbb{R}^m$**, the output space, because $Ax+Ay=A(x+y)$, $c\,Ax=A(cx)$ and $A\mathbf 0=\mathbf 0$.
- Its dimension is the number of independent columns: $\dim\mathcal C(A)=\operatorname{rank}(A)$.
- A **basis** of $\mathcal C(A)$ is given by the **pivot columns of the original matrix $A$** — not those of its echelon form.
- For the paint machine, $\mathcal C(A)=\operatorname{span}\{(1,0,0),(0,0,1)\}=\{(r,0,b)\}$, the red–blue plane; yellow is not on the menu.

:::thm When is $Ax=b$ solvable?
$$
Ax=b\ \text{has a solution}\quad\Longleftrightarrow\quad b\in\mathcal C(A)\quad\Longleftrightarrow\quad \operatorname{rank}(A)=\operatorname{rank}\big([\,A\mid b\,]\big).
$$
If appending $b$ as an extra column raises the rank, then $b$ supplied a new direction, so it was not reachable.
:::

:::example Which vectors are reachable? (revision notes)
Let
$$
A=\begin{bmatrix}1&1&2\\2&1&3\\3&1&4\\4&1&5\end{bmatrix}.
$$
Column 3 is the sum of columns 1 and 2, so $\mathcal C(A)$ is a plane inside $\mathbb{R}^4$.

1. $b=(1,1,1,1)$ is column 2 itself, so it is reachable with $x=(0,1,0)$.
2. $b=(3,5,7,9)$ is column 1 plus column 3, reachable with $x=(1,0,1)$; it is also reachable with $x=(2,1,0)$. There are many recipes because $\mathcal N(A)\neq\{\mathbf 0\}$.
3. $b=(0,0,0,1)$ is **not** reachable. A combination $x_1a_1+x_2a_2$ has first two entries $x_1+x_2$ and $2x_1+x_2$; setting both to zero forces $x_1=x_2=0$, and then the fourth entry is $0$, not $1$.
:::

:::remember
$\mathcal C(A)\subseteq\mathbb{R}^m$ is the set of reachable outputs, and $Ax=b$ is solvable exactly when $b$ belongs to it.
:::

## 5. Null space

:::figs
l03-p09|Null space and rank–nullity
:::

:::def Null space
$$
\mathcal N(A)=\{\,x\in\mathbb{R}^n\ :\ Ax=\mathbf 0\,\}
$$
is the set of all inputs that $A$ sends to zero (the "inverse image" of $\mathbf 0\in\mathbb{R}^m$). It is a **subspace of $\mathbb{R}^n$**, the input space, and its dimension is the **nullity** of $A$.
:::

Two pictures from the revision notes. A lamp shining straight down maps $\mathbb{R}^3$ to the floor $\mathbb{R}^2$ through $A=\begin{pmatrix}1&0&0\\0&1&0\end{pmatrix}$; moving an object vertically does not move its shadow, so $\mathcal N(A)$ is the vertical axis. And $M=\begin{pmatrix}1&2\\2&4\end{pmatrix}$ squashes the whole plane onto the line through $(1,2)$, collapsing the line $\mathcal N(M)=\operatorname{span}\{(2,-1)\}$ to the origin.

**Null-space vectors are recipes for redundancy.** Each $x\in\mathcal N(A)$ records a way in which the columns cancel, $\sum_j x_ja_j=\mathbf 0$. Consequently the columns are independent exactly when $\mathcal N(A)=\{\mathbf 0\}$. (In 2026 Quiz 5, "if $Ax=\mathbf 0$ has only the trivial solution then the rank is exactly $n$" is true.) And if $Ax=\mathbf 0$ for some non-zero $x$, it is the **columns** of $A$ that are dependent — not necessarily the rows, and certainly $A$ need not be zero (2024 Mid, MCQ 18).

### Computing a null space: free variables and special solutions

1. Reduce $A$ to REF or RREF.
2. Variables that correspond to pivot columns are **pivot variables**; the others are **free variables**.
3. For each free variable in turn, set it equal to $1$ and the remaining free variables equal to $0$, and solve for the pivot variables. The result is a **special solution**.
4. The special solutions form a basis of $\mathcal N(A)$. There is one for each free variable, so there are $n-r$ of them.

:::example The slide's rank example
From
$$
\operatorname{rref}(A)=\begin{bmatrix}1&0&-1\\0&1&2\\0&0&0\end{bmatrix},
$$
the variable $x_3$ is free, and the two non-zero rows say $x_1-x_3=0$ and $x_2+2x_3=0$. Setting $x_3=1$,
$$
x=x_3\begin{bmatrix}1\\-2\\1\end{bmatrix},\qquad \mathcal N(A)=\operatorname{span}\left\{\begin{bmatrix}1\\-2\\1\end{bmatrix}\right\}.
$$
This is precisely the column relation $a_1-2a_2+a_3=\mathbf 0$ found earlier. For the $4\times3$ slide example, where $a_3=a_1+a_2$, the same reasoning gives $\mathcal N(A)=\operatorname{span}\{(1,1,-1)\}$, a line in $\mathbb{R}^3$.
:::

:::example Worksheet 2, Problem 1
$$
A=\begin{bmatrix}1&2&1\\-2&-3&1\\3&5&0\end{bmatrix}
\xrightarrow[\;R_3\,\leftarrow\,R_3-3R_1\;]{\;R_2\,\leftarrow\,R_2+2R_1\;}
\begin{bmatrix}1&2&1\\0&1&3\\0&-1&-3\end{bmatrix}
\xrightarrow{\;R_3\,\leftarrow\,R_3+R_2\;}
\begin{bmatrix}1&2&1\\0&1&3\\0&0&0\end{bmatrix}.
$$
**Rank.** There are two pivots, so $\operatorname{rank}A=2$.

**Column space.** The pivot columns of the original matrix form a basis, $\{(1,-2,3),\ (2,-3,5)\}$, so $\mathcal C(A)$ is a plane through the origin in $\mathbb{R}^3$.

**Null space.** The variable $x_3$ is free. The second row gives $x_2=-3x_3$, and the first gives $x_1=-2x_2-x_3=5x_3$. Hence
$$
\mathcal N(A)=\operatorname{span}\left\{\begin{bmatrix}5\\-3\\1\end{bmatrix}\right\},
\qquad\text{and indeed}\qquad
A\begin{bmatrix}5\\-3\\1\end{bmatrix}=\begin{bmatrix}5-6+1\\-10+9+1\\15-15+0\end{bmatrix}=\begin{bmatrix}0\\0\\0\end{bmatrix}.
$$
**Rank–nullity.** $2+1=3$, the number of columns.
:::

:::remember
$\mathcal N(A)\subseteq\mathbb{R}^n$ is the set of inputs the matrix forgets; one special solution for each free variable gives a basis of it.
:::

## 6. The rank–nullity theorem

:::thm Rank–nullity theorem
For every $A\in\mathbb{R}^{m\times n}$,
$$
\operatorname{rank}(A)+\operatorname{nullity}(A)=n,\qquad\text{that is,}\qquad \dim\mathcal C(A)+\dim\mathcal N(A)=\text{the number of columns of }A .
$$
:::

**Why it holds: conservation of dimensions.** We start with $n$ input "knobs". Each input dimension either **survives** as a new output direction, contributing to the rank (a pivot column), or is **crushed** to zero, contributing to the nullity (a free column). Since every column is either a pivot column or a free column, the two counts add up to $n$.

| Matrix | $n$ | rank | nullity | rank + nullity |
|---|---|---|---|---|
| paint machine ($3\times3$) | $3$ | $2$ | $1$ | $3$ |
| $\begin{bmatrix}1&2&3\\2&4&6\\1&1&1\end{bmatrix}$ | $3$ | $2$ | $1$ | $3$ |
| slide example ($4\times3$) | $3$ | $2$ | $1$ | $3$ |
| $\begin{bmatrix}1&2\\2&4\end{bmatrix}$ | $2$ | $1$ | $1$ | $2$ |
| shadow $\begin{bmatrix}1&0&0\\0&1&0\end{bmatrix}$ | $3$ | $2$ | $1$ | $3$ |

:::warn Count columns, not rows
The theorem counts $n$, the number of **columns**. For the $4\times3$ slide example the total is $3$, not $4$. Remember also where each space lives: $\mathcal N(A)\subseteq\mathbb{R}^n$ (inputs) and $\mathcal C(A)\subseteq\mathbb{R}^m$ (outputs). The two cannot be compared unless $m=n$.
:::

:::example 2025 Mid, Problem 6
Let $A\in\mathbb{R}^{5\times7}$ have rank $4$.

1. $\dim\mathcal C(A)=\operatorname{rank}A=4$.
2. By rank–nullity, $\dim\mathcal N(A)=7-4=3$.
3. Is $Ax=b$ solvable for every $b\in\mathbb{R}^5$? **No.** $\mathcal C(A)$ is a four-dimensional proper subspace of $\mathbb{R}^5$, so only those $b$ that lie in it are reachable. Solvability for every $b$ would require rank $5$.

In the revision notes, $W\in\mathbb{R}^{3\times7}$ with rank $3$ has nullity $4$ and $\mathcal C(W)=\mathbb{R}^3$. A $7\times3$ matrix *can* have a trivial null space (if its rank is $3$), but a $3\times7$ matrix never can, since its nullity is at least $4$: **a wide matrix always forgets something**.
:::

:::example Construct a matrix, or prove that none exists (PSet 4, Problem 3)
1. *The column space contains $(1,1,0)$ and $(0,0,1)$, and the row space contains $(1,2)$ and $(2,5)$.* We need a $3\times2$ matrix of rank $2$; for example $\begin{pmatrix}1&0\\1&0\\0&1\end{pmatrix}$.
2. *The column space has basis $\{(1,1,3)\}$ and the null space has basis $\{(3,1,1)\}$.* Then $m=3$, $r=1$, $n=3$ and the nullity is $1$; but rank–nullity requires $1+1=3$. **Impossible.**
3. *$\dim\mathcal N(A)=1+\dim\mathcal N(A^\top)$.* This requires $n-r=1+(m-r)$, that is, $n=m+1$; for example $A=(1\ \ 0)$. (Here $\mathcal N(A^\top)$, the **left null space**, lies in $\mathbb{R}^m$ and has dimension $m-r$, while the **row space** $\mathcal C(A^\top)$ has dimension $r$.)
:::

:::remember
rank + nullity $=n$, the number of columns: every input dimension is either kept (rank) or crushed (nullity).
:::

## 7. Rank and linear systems; the complete solution

**Existence is a column-space question:** is $b\in\mathcal C(A)$? **Uniqueness is a null-space question:** if $x_p$ solves $Ax=b$, then so does $x_p+z$ for every $z\in\mathcal N(A)$, because
$$
A(x_p+z)=Ax_p+Az=b+\mathbf 0=b .
$$
Therefore
$$
\{\text{all solutions of }Ax=b\}=x_p+\mathcal N(A),
$$
one particular solution plus any vector of the null space.

The slide (p5) states three rules for $Ax=b$ in shorthand. Their precise forms are:

| The slide says | Precisely |
|---|---|
| $\operatorname{rank}A=n$ $\Rightarrow$ unique solution | $\mathcal N(A)=\{\mathbf 0\}$, so there is **at most one** solution, and exactly one if $b\in\mathcal C(A)$ |
| $\operatorname{rank}A<n$ $\Rightarrow$ infinitely many | $\mathcal N(A)$ is non-trivial, so **if** a solution exists there are infinitely many (otherwise none) |
| $\operatorname{rank}A<m$ $\Rightarrow$ inconsistent | $\mathcal C(A)\neq\mathbb{R}^m$, so **some** right-hand sides are unreachable, while others may still be reachable |

**The four cases** (PSet 4, Problem 2), with $r=\operatorname{rank}A$:

| Case | Shape | $\mathcal C(A)$ | Solutions of $Ax=b$ | Example |
|---|---|---|---|---|
| $r=m=n$ | square, invertible | all of $\mathbb{R}^m$ | exactly one, for every $b$ | $\begin{pmatrix}1&2\\3&1\end{pmatrix}$ |
| $r=n<m$ | tall, full column rank | a proper subspace | none or one | $\begin{pmatrix}1&0\\0&1\\0&0\end{pmatrix}$ |
| $r=m<n$ | wide, full row rank | all of $\mathbb{R}^m$ | infinitely many, for every $b$ | $\begin{pmatrix}1&0&1\\0&1&1\end{pmatrix}$ |
| $r<m,\ r<n$ | rank-deficient | a proper subspace | none or infinitely many | PSet 4, Problem 1 below |

:::example The complete solution in matrix form (PSet 4, Problem 1)
**Step 1 — eliminate on the augmented matrix.**
$$
\left[\begin{array}{cccc|c}1&2&2&2&b_1\\2&4&6&8&b_2\\3&6&8&10&b_3\end{array}\right]
\xrightarrow[\;R_3\,\leftarrow\,R_3-3R_1\;]{\;R_2\,\leftarrow\,R_2-2R_1\;}
\left[\begin{array}{cccc|c}1&2&2&2&b_1\\0&0&2&4&b_2-2b_1\\0&0&2&4&b_3-3b_1\end{array}\right]
\xrightarrow{\;R_3\,\leftarrow\,R_3-R_2\;}
\left[\begin{array}{cccc|c}1&2&2&2&b_1\\0&0&2&4&b_2-2b_1\\0&0&0&0&b_3-b_2-b_1\end{array}\right].
$$
The pivots are in columns 1 and 3, so $\operatorname{rank}A=2$, and $x_2,x_4$ are free.

**Step 2 — the solvability condition.** The last row requires $b_3-b_2-b_1=0$. So $\mathcal C(A)$ is the plane $b_1+b_2-b_3=0$ in $\mathbb{R}^3$.

**Step 3 — the special solutions.** Setting $(x_2,x_4)=(1,0)$ and then $(0,1)$ and solving for $x_1,x_3$,
$$
s_1=\begin{bmatrix}-2\\1\\0\\0\end{bmatrix},\qquad s_2=\begin{bmatrix}2\\0\\-2\\1\end{bmatrix},\qquad \dim\mathcal N(A)=4-2=2 .
$$
**Step 4 — a particular solution** for $b=(1,5,6)$, which is admissible since $1+5=6$. With the free variables set to zero, the second row gives $2x_3=3$ and the first gives $x_1+2x_3=1$:
$$
x_p=\begin{bmatrix}-2\\0\\3/2\\0\end{bmatrix}.
$$
**Step 5 — the complete solution.**
$$
\boxed{\;x=\begin{bmatrix}-2\\0\\3/2\\0\end{bmatrix}+c_1\begin{bmatrix}-2\\1\\0\\0\end{bmatrix}+c_2\begin{bmatrix}2\\0\\-2\\1\end{bmatrix},\qquad c_1,c_2\in\mathbb{R}.\;}
$$
For $b=(1,5,7)$ there is **no** solution, even though $r<n$. The correct statement is therefore: if $r<n$, there are **either no solutions or infinitely many**.
:::

:::example A singular $2\times2$ system
Let $M=\begin{pmatrix}1&2\\2&4\end{pmatrix}$. The right-hand side $(3,6)=3\,(1,2)$ lies on the line $\mathcal C(M)$, and the solutions form a line parallel to $\mathcal N(M)$:
$$
x=\begin{bmatrix}3\\0\end{bmatrix}+t\begin{bmatrix}2\\-1\end{bmatrix},\qquad t\in\mathbb{R}.
$$
The right-hand side $(3,5)$ is not on the line, since $5\neq2\cdot3$, so $Mx=(3,5)$ has no solution. In the paint machine, likewise, the colour $(1,0,1)$ can be mixed by $(1,1,0)$, by $(0,0,1)$, or by $(1,1,0)+t(-1,-1,1)$ for any $t$: infinitely many recipes, because of the ghost direction.
:::

:::remember
The solutions of $Ax=b$ are one particular solution plus the whole null space; a solution exists exactly when $b\in\mathcal C(A)$, and it is unique exactly when $\mathcal N(A)=\{\mathbf 0\}$.
:::

## 8. Slide example and AI connections

:::figs
l03-p10|The 4×3 slide example
:::

:::example The slide's example (p10)
$$
A=\begin{bmatrix}1&1&2\\2&1&3\\3&1&4\\4&1&5\end{bmatrix},\qquad m=4,\quad n=3 .
$$
Here $\mathcal C(A)$ is a subspace of $\mathbb{R}^4$ and $\mathcal N(A)$ is a subspace of $\mathbb{R}^3$. The third column is the sum of the first two, so exactly two columns are independent. Hence $\mathcal C(A)$ is a **two-dimensional subspace of $\mathbb{R}^4$**, and by rank–nullity $\dim\mathcal N(A)=3-2=1$, with $\mathcal N(A)=\operatorname{span}\{(1,1,-1)\}$.
:::

:::ml Why a machine-learning student should care
- **Regression is a column-space problem.** The predictions $X\theta$ always lie in $\mathcal C(X)$. With far more samples than features ($n\gg d$), $\mathcal C(X)$ is a thin slice of $\mathbb{R}^n$ and the target $y$ is almost never in it, so we settle for the closest reachable point. That is **least squares** (L05).
- **Redundant features create a null space.** If one column is height in centimetres and another is height in inches, the columns are dependent, and $\theta$ and $\theta+tz$ with $z\in\mathcal N(X)$ give identical predictions; the model cannot decide how to split the credit. The remedy is to drop duplicates or to regularise (ridge regression, L05). This is the multicollinearity problem of the 2024 Mid.
- **Compression uses low rank.** A matrix of rank $r$ can be stored as $r$ outer products using far fewer numbers — an idea that returns with the SVD, PCA and low-rank fine-tuning of large models.
:::

- **2025 Quiz 3:** the rank of a $3\times3$ matrix, and what it says about its columns and column space.
- **Mid MCQs:** rank + nullity $=n$ (true); $\operatorname{rank}A=\operatorname{rank}A^\top$ (true); "the rank equals the number of rows" (false); "rank $m$ implies independent columns" (false). For a $4\times3$ matrix of rank $3$: independent columns, $\mathcal N=\{\mathbf 0\}$, row space of dimension $3$ and $\dim\mathcal C=3$ (all true).
- **Mid problem:** a $5\times7$ matrix of rank $4$ — the dimensions of $\mathcal C$ and $\mathcal N$, and whether every $b$ is reachable.

:::remember The one line for this lecture
A matrix reaches exactly its column space, of dimension equal to the rank, and forgets exactly its null space, of dimension $n-\operatorname{rank}$; the system $Ax=b$ is solvable precisely when $b\in\mathcal C(A)$, and then every solution has the form $x_p+\mathcal N(A)$.
:::
