# Start here

How to use this site in the four days before the mid, and after it.

## If the mid is in a few days

1. **Day 1–2 — notes, one lecture per sitting.** Read a lecture's notes with the slides PDF open beside it. At every ★ Remember line, cover the page and say the line aloud (the vivas reward explaining, not just computing). Then do one mock quiz for that lecture under a 20-minute timer.
2. **Day 3 — Mock Mid 1 and Mock Mid 2** in exam conditions (45 + 100 minutes). Mark them strictly with the −1 rule for wrong ticks. Re-read the notes sections for every question you lost marks on.
3. **Day 4 — the real 2024 and 2025 papers** (links on the [mid guide](mid-guide.html)), then Mock Mid 3, then the formula sheet one last time.

## How the pages are built

- **Notes** follow the order of the lecture slides. Coloured boxes: blue = definition, purple = theorem/derivation, green = worked example, red = common trap, yellow = how it was examined / where it is used in AI, and the rust-coloured **★ Remember** box closes every section.
- **Practice quizzes** are new questions written in the pattern of the quizzes actually set in 2026 (and in 2025). Solutions and marking are hidden under each question — try first.
- **Mock mids** copy the mid format exactly: Part I select-all MCQs with negative marking, Part II problems.
- All working for linear algebra is written as matrices and column vectors.
